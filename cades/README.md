# Скрипт КриптоПро для подписи по ГОСТ

Положите сюда `cadesplugin_api.js` — официальный скрипт КриптоПро ЭЦП Browser plug-in. В образ он не входит:
его скачивают с сайта КриптоПро после принятия условий. Каталог монтируется в контейнер `web`
(`./cades:/usr/share/nginx/cades:ro`), перезапуск не нужен. Без файла подпись по ГОСТ в интерфейсе недоступна,
остальное работает как раньше. Подробности — [docs/operations/gost-signature.md](../docs/operations/gost-signature.md).

Файл `*.js` в git не попадает (`.gitignore`).
