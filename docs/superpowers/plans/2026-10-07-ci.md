# Carbone Reports — План 5: CI и публикация образов

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** GitHub Actions на каждый push и PR проверяет typecheck, lint, форматирование, модульные и интеграционные тесты. После зелёных проверок на `main` и тегах `v*` образы api и web публикуются в GHCR. Compose умеет запускаться из готовых образов.

**Architecture:** Один workflow `.github/workflows/ci.yml` из трёх заданий: `checks` → `integration` → `images` (`needs`). Образы собираются `docker/build-push-action` с кэшем GitHub Actions, теги задаёт `docker/metadata-action`. Compose получает `image:` с переменными окружения, сборка `build:` остаётся.

**Tech Stack:** GitHub Actions (`actions/checkout@v4`, `pnpm/action-setup@v4`, `actions/setup-node@v4`, `docker/setup-buildx-action@v3`, `docker/login-action@v3`, `docker/metadata-action@v5`, `docker/build-push-action@v6`), GHCR, testcontainers.

**Spec:** `docs/superpowers/specs/2026-10-02-carbone-reports-design.md`, §16.

## Global Constraints

- Node 22, pnpm 10.34.6 (точная версия из `packageManager` в корневом `package.json`; если поля нет, задать `version: 10.34.6` в `pnpm/action-setup`).
- Права workflow по умолчанию — `contents: read`. `packages: write` получает только задание `images`.
- Публикация идёт только при `push` в `main` или на тег `v*` и никогда на PR.
- Имена образов строчными буквами: `ghcr.io/samrozhkov/carbone-report-api`, `ghcr.io/samrozhkov/carbone-report-web`.
- Секреты в workflow не нужны: `GITHUB_TOKEN`.
- Локальная работа (`pnpm stack:demo`, `stack:dev`, `stack:prod`) не должна измениться.
- Тексты README на русском.
- Перед коммитом: `pnpm typecheck && pnpm lint && pnpm exec prettier --check . && pnpm test`. Задача 1 дополнительно запускает `pnpm test:int`.
- Пуш на GitHub разрешён только для ветки `feat/ci` в `origin` (репозиторий пользователя). В `main` не пушить.

## Review Focus

1. **Интеграционные тесты на раннере без IPv6 для Docker.** Ожидание: `ssl.int.test.ts` не зависит от `::1`. Проверка: Task 1, затем реальный прогон в Task 3.
2. **Ветка `stack:dev` после добавления `image:` в базовый compose.** Ожидание: dev-сборка не перетирает прод-тег образа `carbone-reports-api` своей dev-стадией, или это явно учтено. Проверка: Task 1, команда `docker compose -f docker-compose.yml -f docker-compose.dev.yml config`.
3. **PR из форка или в PR.** Ожидание: `images` не пытается войти в GHCR и ничего не публикует. Проверка: Task 2, условия `if:` в шагах login и push.
4. **Повторный push той же ветки.** Ожидание: предыдущий прогон отменяется, публикация на `main` не отменяется на середине. Проверка: Task 2, `concurrency` с `cancel-in-progress` только не для `main`.
5. **Кэш pnpm и сборка нативного argon2 на раннере.** Ожидание: `pnpm install --frozen-lockfile` проходит, argon2 собирается или берёт prebuild. Проверка: Task 3, реальный прогон.

### Task 2: Workflow CI

**Files:**
- Create: `.github/workflows/ci.yml`

**Interfaces:**
- Consumes: корневые скрипты `typecheck`, `lint`, `test`, `test:int`; `docker/api.Dockerfile`, `docker/web.Dockerfile` (контекст сборки — корень репозитория).

- [ ] **Step 1: Workflow**

`.github/workflows/ci.yml`:
```yaml
name: CI

on:
  push:
    branches: ['**']
    tags: ['v*']
  pull_request:
    branches: [main]

permissions:
  contents: read

concurrency:
  group: ci-${{ github.ref }}
  # main и теги не отменяем: публикация образов не должна обрываться на середине.
  cancel-in-progress: ${{ github.ref != 'refs/heads/main' && !startsWith(github.ref, 'refs/tags/') }}

jobs:
  checks:
    name: Проверки и модульные тесты
    runs-on: ubuntu-latest
    timeout-minutes: 15
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: pnpm
      - run: pnpm install --frozen-lockfile
      - run: pnpm typecheck
      - run: pnpm lint
      - run: pnpm exec prettier --check .
      - run: pnpm test

  integration:
    name: Интеграционные тесты
    runs-on: ubuntu-latest
    timeout-minutes: 20
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: pnpm
      - run: pnpm install --frozen-lockfile
      - run: pnpm test:int

  images:
    name: Образы ${{ matrix.name }}
    needs: [checks, integration]
    runs-on: ubuntu-latest
    timeout-minutes: 30
    permissions:
      contents: read
      packages: write
    strategy:
      fail-fast: false
      matrix:
        include:
          - name: api
            dockerfile: docker/api.Dockerfile
          - name: web
            dockerfile: docker/web.Dockerfile
    env:
      PUBLISH: ${{ github.event_name == 'push' && (github.ref == 'refs/heads/main' || startsWith(github.ref, 'refs/tags/v')) }}
    steps:
      - uses: actions/checkout@v4
      - uses: docker/setup-buildx-action@v3
      - name: Вход в GHCR
        if: env.PUBLISH == 'true'
        uses: docker/login-action@v3
        with:
          registry: ghcr.io
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}
      - id: meta
        uses: docker/metadata-action@v5
        with:
          images: ghcr.io/samrozhkov/carbone-report-${{ matrix.name }}
          tags: |
            type=sha,prefix=sha-
            type=ref,event=branch
            type=raw,value=latest,enable={{is_default_branch}}
            type=semver,pattern={{version}}
            type=semver,pattern={{major}}.{{minor}}
      - uses: docker/build-push-action@v6
        with:
          context: .
          file: ${{ matrix.dockerfile }}
          push: ${{ env.PUBLISH == 'true' }}
          tags: ${{ steps.meta.outputs.tags }}
          labels: ${{ steps.meta.outputs.labels }}
          cache-from: type=gha,scope=${{ matrix.name }}
          cache-to: type=gha,mode=max,scope=${{ matrix.name }}
```
Проверьте:
- **`packageManager` в корневом `package.json`.** Если поля нет, у обоих шагов `pnpm/action-setup@v4` добавьте `with: version: 10.34.6`.
- **Целевые стадии Dockerfile.** Если у них несколько стадий и прод-стадия не последняя, добавьте `target:`. Сверьте с тем, как собирает `docker-compose.yml`: в `build.target` указана стадия или нет.
- **Сборка `web.Dockerfile` из контекста репозитория.** Он может требовать файлы, которых нет в git, например `certs/`. Если они нужны только в runtime, через volume, сборка от них не зависит. Если без них сборка падает, это BLOCKED с описанием.

- [ ] **Step 2: Проверка синтаксиса локально**

```bash

```
Expected: без ошибок. Если образ недоступен, проверьте YAML хотя бы так: `node -e "require('yaml')"`. Если пакета `yaml` нет, проверьте другим доступным способом и укажите в отчёте, каким.

```bash

```
Expected:

- [ ] **Step 2: Если что-то упало**

```bash
gh run view <id> --log-failed | tail -100
```
Чините причину в коде или workflow, коммитьте, пушьте и наблюдайте снова. Типичные причины:
- argon2 без prebuild: нужен `python3`/`build-essential`, на ubuntu-latest они есть;
- testcontainers не находит Docker;
- версия pnpm;
- таймауты.

Не ослабляйте проверки: не отключайте тесты, не добавляйте `continue-on-error`. Если тест падает только в CI, разберитесь почему. Если проблема в самом тесте, а не в продукте, исправьте тест и объясните это в отчёте.
