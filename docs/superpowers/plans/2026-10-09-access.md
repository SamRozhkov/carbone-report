# Carbone Reports — План 8: группы пользователей и доступ к отчётам

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Админ заводит группы пользователей и категории отчётов и выдаёт группам доступ к категориям и к отдельным шаблонам. Шаблоны и категории можно сделать «доступными всем». Пользователь видит и формирует только доступные ему отчёты. Каталог отчётов сгруппирован по категориям.

**Architecture:**
- Пять новых таблиц и два поля у `templates`, добавленные миграцией drizzle. Существующие шаблоны становятся «доступными всем».
- Модуль `apps/api/src/modules/access/` содержит единственное правило доступа: `accessibleTemplates(user)` — SQL-условие для списков, `assertTemplateAccess(db, user, id)` — проверка для карточки.
- Новые маршруты `/api/groups`, `/api/categories`, `/api/templates/:id/access`, `/api/users/:id/groups`.
- В интерфейсе: страницы «Группы» и «Категории», раздел «Доступ» во вкладке «Настройки» шаблона, группы в диалоге пользователя, каталог по категориям.

**Tech Stack:** drizzle, Fastify, zod, React 19 + Gravity UI, TanStack Query, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-02-carbone-reports-design.md`, §19.

## Global Constraints

- Правило доступа: админ видит всё. Пользователь видит шаблон, если выполнено хотя бы одно условие:
  - `templates.public`;
  - у шаблона есть категория и `categories.public`;
  - есть группа пользователя в `category_groups` категории шаблона;
  - есть группа пользователя в `template_groups` шаблона.
- Недоступный шаблон неотличим от несуществующего и отдаёт 404 `notFound('шаблон')`.
- История: пользователь видит свои запуски и скачивает их файлы независимо от текущего доступа к шаблону. `/api/runs` не меняется.
- Названия групп и категорий уникальны (без учёта регистра) и непусты после `trim`. При конфликте — 409 «группа с таким названием уже существует» или «категория с таким названием уже существует».
- Удаление группы удаляет её связи с пользователями, категориями и шаблонами. Удаление категории ставит у шаблонов `category_id = null`.
- Новые шаблоны, созданные или загруженные, закрыты: `public = false`, без категории. Дубликат копирует категорию, `public` и группы исходника.
- Тексты на русском.
- Гейты: `pnpm typecheck && pnpm lint && pnpm exec prettier --check . && pnpm test`, при изменениях в API ещё `pnpm test:int`.
- Docker на OrbStack. Перед `build`/`up` проверять `df -h /System/Volumes/Data`: меньше 2 ГБ — BLOCKED. `down` без `-v`. Удалять только висячие образы `carbone-reports`.

## Review Focus

1. **Пользователь знает id чужого шаблона.** Ожидание: 404 на карточке, генерации, предпросмотре и вариантах параметров, без утечки названия. Проверка: Task 1.
2. **Существующая установка после выката.** Ожидание: все шаблоны остаются видны всем пользователям (`public = true` после миграции), а новые шаблоны закрыты. Проверка: Task 1, интеграционный тест миграции.
3. **Пользователя удалили из группы, у которой был доступ.** Ожидание: шаблон пропадает из каталога при следующем запросе, история запусков остаётся. Проверка: Task 1, Task 2.
4. **Удалили категорию с доступом группы.** Ожидание: шаблоны остаются без категории и видны только по своим собственным правилам. Проверка: Task 2.
5. **Админ сделал шаблон закрытым, не выдав доступ ни одной группе.** Ожидание: шаблон видит только админ, а в настройках шаблона видно предупреждение «шаблон сейчас доступен только администраторам». Проверка: Task 3.

export const categories = pgTable('categories', {
  id: uuid('id').primaryKey().defaultRandom(),
  name: text('name').notNull(),

export const categoryGroups = pgTable('category_groups', {
  categoryId: uuid('category_id').notNull().references(() => categories.id, { onDelete: 'cascade' }),

export const templateGroups = pgTable('template_groups', {
  templateId: uuid('template_id').notNull().references(() => templates.id, { onDelete: 'cascade' }),

- [ ] **Step 3: Правило**

`apps/api/src/modules/access/access.ts`:
```ts
import { and, eq, exists, or, sql, type SQL } from 'drizzle-orm';
import type { Db } from '../../db/client';
import { categories, categoryGroups, templateGroups, templates, userGroups } from '../../db/schema';
import { notFound } from '../../lib/errors';
import type { SessionUser } from '../auth/session';

/** Единственное правило доступа к шаблону (§19.1). undefined — без ограничений (админ). */
export function accessibleTemplates(user: SessionUser): SQL | undefined {
  if (user.role === 'admin') return undefined;
  return or(
    eq(templates.public, true),
    exists(sql`select 1 from ${categories} where ${categories.id} = ${templates.categoryId} and ${categories.public}`),
    exists(sql`select 1 from ${categoryGroups} join ${userGroups} on ${userGroups.groupId} = ${categoryGroups.groupId}
                where ${categoryGroups.categoryId} = ${templates.categoryId} and ${userGroups.userId} = ${user.id}`),
    exists(sql`select 1 from ${templateGroups} join ${userGroups} on ${userGroups.groupId} = ${templateGroups.groupId}
                where ${templateGroups.templateId} = ${templates.id} and ${userGroups.userId} = ${user.id}`),
  );
}

export async function assertTemplateAccess(db: Db, user: SessionUser, templateId: string): Promise<void> {
  if (user.role === 'admin') return;
  const [row] = await db.select({ id: templates.id }).from(templates)
    .where(and(eq(templates.id, templateId), accessibleTemplates(user)));
  if (!row) throw notFound('шаблон');
}
```
Проверьте, что `${categories.public}` и прочие обращения к колонкам внутри `sql` дают полные имена (`"categories"."public"`). Если подзапросы ссылаются на внешнюю таблицу неоднозначно, задайте алиасы. Модульного теста здесь нет, правило проверяют интеграционные тесты.
