# 2.1.0: версия сборки, CHANGELOG, лицензия — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Интерфейс показывает версию сборки интерфейса и сервера, у проекта есть CHANGELOG с публикацией в выпуск GitHub и лицензия PolyForm Strict 1.0.0.

**Architecture:** Версия, коммит и дата сборки приходят в образы аргументами сборки (CI берёт их из тега и коммита), API отдаёт их на `GET /api/version`, web встраивает свои при сборке Vite и сравнивает с серверными в окне «О программе». CHANGELOG.md — источник описания выпуска; CI проверяет раздел на теге и создаёт выпуск на GitHub.

**Tech Stack:** Node 22, Fastify 5, React 19 + Gravity UI (`@gravity-ui/navigation` `FooterItem`), Vite, vitest, Docker buildx, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-02-carbone-reports-design.md`, §30.

## Global Constraints

- Ветка `feat/2.1.0`. Слияние в `main` и тег — только контроллер, с отдельного разрешения владельца.
- Node 22: `export PATH=$HOME/.nvm/versions/node/v22.17.0/bin:$PATH` перед `pnpm`/`node`.
- Тексты для пользователя, журналы и комментарии — на русском, в стиле окружающего кода.
- Секреты не печатаются; `.env` и `certs/` не коммитятся.
- Каждый коммит заканчивается строкой `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Перед коммитом: `pnpm exec prettier --check .`, `pnpm lint`, `pnpm typecheck` — зелёные; тесты затронутых пакетов — зелёные.
- Интеграционные тесты с Docker локально не запускать (их гоняет CI). Образы локально не собирать, кроме явно указанного шага.
- Значения по умолчанию: `version` = `dev`, `commit` = `unknown`, `builtAt` = `unknown`.
- `GET /api/health` и `/api/ready` не меняются.

## Review Focus

1. Сборка без аргументов (локальный `docker compose build`, `pnpm dev`) — интерфейс показывает «Версия dev», окно открывается, предупреждения о расхождении нет, если сервер тоже `dev`/`unknown`. Тест: Task 2.
2. Сервер недоступен или вернул 401/500 на `/api/version` — окно «О программе» показывает свою версию и «Версия сервера недоступна», без падения страницы. Тест: Task 2.
3. Выпуск по тегу без раздела в CHANGELOG — CI падает до публикации образов и чарта. Тест: Task 4 (тест скрипта: нет раздела → код 1).
4. Раздел CHANGELOG последней версии в конце файла перед ссылками сравнения — скрипт не захватывает ссылки. Тест: Task 4.
5. `/api/version` без сессии — 401, а не утечка версии. Тест: Task 1.
