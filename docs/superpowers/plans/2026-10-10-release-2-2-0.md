# 2.2.0: агрегаторы и drop/keep — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Агрегаторы Carbone EE (`aggSum` … `cumCountD`, `:count()`) и `drop`/`keep` работают во встроенной сборке Carbone; справка показывает их как доступные.

**Architecture:** Правки в `packages/carbone` (форк CE 3.8.2): функции убираются из `DISABLED` (`lib/community.js`); агрегаторы требуют данных всего набора — вычисляются на этапе построения (`lib/builder.js`), а не как обычные форматтеры одного значения; `drop`/`keep` помечают элемент XML и удаляют его постобработкой по типу файла. Справка (`apps/web/src/pages/admin/help/content.ts`) проверяется `pnpm help:check` на этой же сборке.

**Tech Stack:** Node 22, mocha (`packages/carbone`), tsx-скрипт `help:check`, vitest (web).

**Spec:** `docs/superpowers/specs/2026-10-02-carbone-reports-design.md`, §31; справочник поведения — `docs/superpowers/notes/2026-10-10-ee-aggregators-drop-sort.md`.

- Node 22: `export PATH=$HOME/.nvm/versions/node/v22.17.0/bin:$PATH`.
- Правило чистой реализации: код образа `carbone-ee` и любой закрытый код Carbone не читается и не скачивается; источник — справочник (открытая документация). Код CE 3.8.2 в `packages/carbone` — наш.

Исключение — эталоны, где EE отвечает «disabled in the Community Edition» для включаемых функций: у них ставится `deviation` с причиной «платная функция реализована в 2.2.0» (не удалять эталоны).
- Сообщения об ошибках шаблона — на русском, как остальные наши ошибки в `packages/carbone`; комментарии — на русском.
- Каждый коммит заканчивается `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Перед коммитом: `pnpm exec prettier --check .`, `pnpm lint`, `pnpm typecheck`, `pnpm --filter @carbone-reports/carbone test`.

## Review Focus

1. Шаблон 2.1.0 без агрегаторов и `drop` собирается байт-в-байт как раньше (весь набор `packages/carbone` зелёный).
2. Агрегатор вне цикла в документе, где тот же массив ещё и выводится циклом `[i]`, — итог не зависит от порядка меток в документе. Тест: Task 1.

4. `drop(row)` во всех строках таблицы — таблица без строк данных остаётся валидным DOCX/XLSX (открывается, конвертируется). Тест: Task 3 (валидность XML: у таблицы DOCX остаётся хотя бы одна `w:tr`, иначе удаляется таблица целиком — решение задачи записать в отчёт и в §31.2).
5. `drop` с неподдержанным элементом для формата — понятная ошибка, а не повреждённый файл. Тест: Task 3.
