## Review Focus

1. **Повтор ошибки в ту же миллисекунду.** Два callback-а со статусом 3 подряд получают одинаковую ISO-метку (JS `Date` хранит миллисекунды). Тогда вкладка «Документ» снова покажет таймаут. Ожидание: метка строго растёт (`greatest(now(), прежняя + 1 мс)`). Тест: Task 3, «метка ошибки строго растёт, даже если часы не сдвинулись».
2. **Проверка `REDIS_PASSWORD` отвергает правильный пароль.** Причины: compose съел `$` (нужен `$$`), шаблон `case` сломан кавычками YAML или прописные A-F не проходят. Тогда стек не поднимается на рабочих установках. Тест: Task 1, Step 1 (отрисованная команда содержит `case "$REDIS_PASSWORD"`) и Step 4 (верхний и нижний регистр → PONG, `abc/def` и пустая строка → код 1).
3. **Monaco без подсветки.** При выборочном импорте язык не зарегистрирован, и `sql`/`json` молча показываются как обычный текст. Или воркер не грузится под CSP. Тест: Task 5, E2E `admin-data.spec.ts` (токены не `mtk1` в группах «SQL» и «Данные отчёта» + проверка CSP в фикстуре) и юнит-тест `monaco-setup.test.ts`.
4. **Пустой порт подменяется или уходит на сервер.** Значение `null` превращается в 5432 или в `NaN`/`null` в теле запроса, либо ошибка «укажите порт» не исчезает после ввода. Тест: Task 4, `DatasourcesPage.test.tsx`, «пустой порт…».
5. **«Отменить» и неактивные кнопки ломают существующие сценарии.** Варианты: сохранение без правок раньше было разрешено (старые тесты), «Отменить» при устаревшем черновике возвращает старый baseline вместо свежего шаблона с сервера, «Отменить» в «Доступе» не сбрасывает предупреждение. Тест: Task 4, тесты `SettingsTab` («Отменить» после обновления шаблона), `DataTab`, раздел «Доступ».

interface Deferred {
  promise: Promise<void>;
  resolve: () => void;
}
function deferred(): Deferred {
  let resolve!: () => void;
  const promise = new Promise<void>((r) => {
    resolve = r;
  });
  return { promise, resolve };
}
