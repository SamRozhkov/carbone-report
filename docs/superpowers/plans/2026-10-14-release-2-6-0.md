# 2.6.0: графики ECharts (`:chart`) и конструктор графиков — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Встроенная сборка Carbone рисует графики ECharts 5 по тегу `{d.x:chart}` в замещающем тексте картинки-заглушки во всех шести форматах (PNG через resvg-js, шрифт Noto Sans из пакета), а в редакторе шаблона есть вкладка «Графики»: конструктор сохраняет описания графиков, API кладёт готовые описания ECharts в `d.charts.<key>` для отчёта и предпросмотра, графики переносятся между средами.

**Architecture:** Движок: новый модуль `packages/carbone/lib/echarts-render.js` (разбор значения, лимиты, ECharts SSR → SVG → PNG) подключается к загрузчику картинок `lib/media.js` как вид `chart` (как `barcode` в 2.4.0): форматтер `chart` передаёт вид своему `__img`, `media.finish` добавляет записи реестра размер рамки (`framePx` в `lib/media-formats.js`), `LOADERS.chart` рисует PNG, дальше общий путь картинок (imageFit, лимит 50 МБ). Конструктор: zod-схема `TemplateChart` и чистая функция `buildChartOption(chart, rows)` в `packages/shared/src/charts.ts`; таблица `template_charts` (миграция 0007), `PUT /api/templates/:id/charts`, `injectCharts` после `buildReportData` в `collectReportData`; перенос (`TransferChart`); вкладка `ChartsTab` с предпросмотром ECharts в браузере (ленивый чанк). Формат чисел конструктора проходит через JSON как строка-маркер `cr:number:{…}` в `formatter`/`valueFormatter`, движок и предпросмотр заменяют её функцией с одинаковой логикой.

**Tech Stack:** Node 22, CommonJS (`packages/carbone`), mocha; `echarts =5.6.0` (Apache-2.0; зависимости `zrender` 5.6.1 — BSD-3-Clause, `tslib` 2.3.0 — 0BSD), `@resvg/resvg-js =2.6.2` (MPL-2.0, готовые сборки по платформам), Noto Sans Regular/Bold (OFL-1.1); TypeScript, zod 4, vitest; Fastify 5 + drizzle-orm/drizzle-kit (Postgres); React 19 + Gravity UI; OnlyOffice Document Server в интеграционном тесте.

**Spec:** `docs/superpowers/specs/2026-10-02-carbone-reports-design.md`, §35 (и §32.1 — правила картинки-заглушки, §34 — контекст 2.5.0).

## Решения контроллера (там, где спецификация молчит)

- R1. Ошибки движка — тексты §35 без префикса; ошибки, брошенные ECharts или resvg, — «график: <сообщение>». Метку показывает суффикс Source (API: «ошибка шаблона: график: xAxis "0" not found Source: "{d.c:chart}"»).
- R2. 5 с проверяются после ECharts и после resvg (код синхронный, прервать его нельзя); `LIMITS.ms` в `echarts-render.js` меняют только тесты.
- R3. Размер без `width`/`height` — рамка заглушки в px при 96 dpi, зажатая в 100–4000; без рамки — 600×400. XLSX `twoCellAnchor` — размер `a:xfrm/a:ext` картинки.
- R4. Формат чисел конструктора применяется всегда (десятичный разделитель — запятая, тысячи и суффикс — через U+00A0). В JSON нет функций, поэтому `buildChartOption` пишет в `formatter`/`valueFormatter` строку `cr:number:{"decimals":…,"thousands":…,"suffix":…}`; движок и предпросмотр заменяют её функцией (`numberFormatter`/`chartNumberFormatter`), одинаковые примеры в тестах обеих сторон. Подпись круговой — «имя: значение».
- R5. Дата-время в подписи — дата из ISO-строки как есть (UTC), без пересчёта в часовой пояс: `2026-01-10T21:30:00.000Z` → `10.01.2026` (в справке: группировать по `created::date`).
- R6. `axisX` — горизонтальная ось, `axisY` — вертикальная (у `barHorizontal` ось значений горизонтальна); у `barHorizontal` категории сверху вниз (`inverse: true`).
- R7. При `splitBy` цвет ряда запрещён (цвета — из палитры); ряд без строки в категории — `null`.
- R8. `PUT …/queries` при графиках: ключ `charts` — ошибка; удалить запрос графика или перевести его в «Одна строка» нельзя («запрос используется графиком …»).
- R9. Точки = сумма длин `series[].data` + строки `dataset.source` (массив — длина, объект колонок — сумма длин колонок).
- R10. `chart` — без аргументов (`chart()` допустим), иначе «chart пишется без аргументов: {d.x:chart}»; `chart` и `barcode` в одной метке — «chart и barcode — в разных метках».

## Review Focus

1. Числа из Postgres: `numeric` приходит строкой, если не помещается в безопасное целое (`"12345678901234567890.5"`), плюс `"-3"`, `"1e3"`, `null`, `"1 234"`, `"abc"`, `"1e400"`, колонка с опечаткой в SQL-алиасе — первые три становятся числами, прочие дают `null` (пропуск точки, не 0), нет колонки — `400` с ключом графика. 3. Огромное или враждебное описание из SQL: > 1 МБ, 10 001 точка, 21 ряд, ключ `__proto__`, строка `"function(){…}"` в `formatter`, вложенность 1000, `theme: 'light'`, ошибка ECharts — ошибка шаблона с меткой или безопасная отрисовка; после ошибки поток не держат таймеры (`dispose` в `finally`). 5. Привязка и размер заглушки в XLSX/ODS/ODP/PPTX: `twoCellAnchor` (from/to не меняются, размер — `a:xfrm`), рамки ODF в см, PPTX `a:xfrm`; и паритет предпросмотра с сервером — формат чисел одинаков в `packages/shared` и в движке (общая таблица примеров). Тест: Task 2 (привязки), Task 1 и Task 3 (таблица формата).

  var _started = Date.now();
  var _instance = null;

// ---- Описание ECharts (§35.4) ----

/** Значение для `{d.charts.<key>:chart}`. */
export interface ChartValue {
  type: 'echarts@v5';
  option: Record<string, unknown>;
}

/** Ошибка данных графика (нет колонки, больше 20 рядов): API отвечает 400 CARBONE_TEMPLATE. */
export class ChartDataError extends Error {}

const isRecord = (v: unknown): v is Record<string, unknown> =>
  typeof v === 'object' && v !== null && !Array.isArray(v);

/** Значение точки: число; строка-число (Postgres numeric) — число; иначе null (пропуск точки). */
export function chartValue(v: unknown): number | null {
  if (typeof v === 'number') return Number.isFinite(v) ? v : null;
  if (typeof v === 'string' && NUMBER_RE.test(v)) {
    const n = Number(v);
    return Number.isFinite(n) ? n : null;
  }
  return null;
}

/** Подпись: строка; дата и дата-время (ISO, UTC) — ДД.ММ.ГГГГ без пересчёта пояса (R5); null — пусто. */
export function chartLabel(v: unknown): string {
  if (v === null || v === undefined) return '';
  const s =
    v instanceof Date
      ? Number.isNaN(v.getTime())
        ? ''
        : v.toISOString()
      : typeof v === 'object'
        ? JSON.stringify(v)
        : String(v);
  const m = DATE_RE.exec(s);
  return m ? `${m[3]}.${m[2]}.${m[1]}` : s;
}

/** Формат чисел конструктора — для подписей, осей и подсказок (R4). Та же логика — echarts-render.js. */
export function formatChartNumber(v: number, f: ChartNumberFormat): string {
  const fixed = f.decimals === null ? String(v) : v.toFixed(f.decimals);
  const m = /^(-?)(\d+)(?:\.(\d+))?$/.exec(fixed);
  let text = fixed;
  if (m) {
    const int = f.thousands ? m[2]!.replace(/\B(?=(\d{3})+(?!\d))/g, NBSP) : m[2]!;
    text = m[1]! + int + (m[3] !== undefined ? `,${m[3]}` : '');
  }
  return f.suffix ? text + NBSP + f.suffix : text;
}

/** Маркер формата для JSON-описания: функции через JSON не проходят. */
export const chartNumberRef = (f: ChartNumberFormat): string =>
  CHART_NUMBER_PREFIX +
  JSON.stringify({ decimals: f.decimals, thousands: f.thousands, suffix: f.suffix });

/** Функция по маркеру `cr:number:{…}` (число или параметры подписи ECharts) или null. */
export function chartNumberFormatter(ref: unknown): ((x: unknown) => string) | null {
  if (typeof ref !== 'string' || !ref.startsWith(CHART_NUMBER_PREFIX)) return null;
  let raw: unknown;
  try {
    raw = JSON.parse(ref.slice(CHART_NUMBER_PREFIX.length));
  } catch {
    return null;
  }
  const parsed = ChartNumberFormat.safeParse(raw);
  if (!parsed.success) return null;
  const f = parsed.data;
  return (x) => {
    if (typeof x === 'number') return formatChartNumber(x, f);
    if (isRecord(x)) {
      const value = Array.isArray(x.value) ? x.value[x.value.length - 1] : x.value;
      const text =
        typeof value === 'number'
          ? formatChartNumber(value, f)
          : value === null || value === undefined
            ? ''
            : String(value);
      return x.seriesType === 'pie' ? `${x.name == null ? '' : String(x.name)}: ${text}` : text;
    }
    return x === null || x === undefined ? '' : String(x);
  };
}

/** Копия описания: маркеры формата → функции (предпросмотр в браузере), `__proto__` отброшен. */
export function reviveChartFormatters<T>(option: T): T {
  const walk = (v: unknown, depth: number): unknown => {
    if (depth >= 64) return v;
    if (Array.isArray(v)) return v.map((x) => walk(x, depth + 1));
    if (!isRecord(v)) return v;
    const out: Record<string, unknown> = {};
    for (const [k, x] of Object.entries(v)) {
      if (k === '__proto__') continue;
      const fn = k === 'formatter' || k === 'valueFormatter' ? chartNumberFormatter(x) : null;
      out[k] = fn ?? walk(x, depth + 1);
    }
    return out;
  };
  return walk(option, 0) as T;
}

interface SeriesData {
  name: string;
  values: (number | null)[];
  source: ChartSeries;
}

function requireColumns(chart: TemplateChart, rows: Record<string, unknown>[]): void {
  const first = rows[0];
  if (!first) return;
  const columns = [
    chart.category,
    ...chart.series.map((s) => s.column),
    ...(chart.splitBy ? [chart.splitBy] : []),
  ];
  for (const c of columns)
    if (!Object.hasOwn(first, c)) throw new ChartDataError(`график ${chart.key}: нет колонки ${c}`);
}

function plainData(chart: TemplateChart, rows: Record<string, unknown>[]) {
  return {
    categories: rows.map((r) => chartLabel(r[chart.category])),
    series: chart.series.map(
      (s): SeriesData => ({
        name: s.name || s.column,
        values: rows.map((r) => chartValue(r[s.column])),
        source: s,
      }),
    ),
  };
}

/** «Ряды из данных»: категории и ряды по первому появлению, пропуск — null, повтор пары — последняя строка. */
function splitData(chart: TemplateChart, rows: Record<string, unknown>[]) {
  const s = chart.series[0]!;
  const by = chart.splitBy!;
  const categories: string[] = [];
  const catIndex = new Map<string, number>();
  const names: string[] = [];
  const nameIndex = new Map<string, number>();
  const cells = new Map<string, number | null>();
  for (const r of rows) {
    const c = chartLabel(r[chart.category]);
    if (!catIndex.has(c)) {
      catIndex.set(c, categories.length);
      categories.push(c);
    }
    const n = chartLabel(r[by]);
    if (!nameIndex.has(n)) {
      if (names.length >= MAX_CHART_SERIES)
        throw new ChartDataError(`график ${chart.key}: больше ${MAX_CHART_SERIES} рядов`);
      nameIndex.set(n, names.length);
      names.push(n);
    }
    cells.set(`${catIndex.get(c)}:${nameIndex.get(n)}`, chartValue(r[s.column]));
  }
  return {
    categories,
    series: names.map(
      (name, si): SeriesData => ({
        name,
        values: categories.map((_, ci) => cells.get(`${ci}:${si}`) ?? null),
        source: s,
      }),
    ),
  };
}

function legendOf(chart: TemplateChart): Record<string, unknown> {
  switch (chart.legend) {
    case 'none':
      return { show: false };
    case 'top':
      return { top: chart.title ? 32 : 8 };
    case 'right':
      return { right: 8, top: 'middle', orient: 'vertical' };
    default:
      return { bottom: 8 };
  }
}

const named = (name: string, gap: number) =>
  name ? { name, nameLocation: 'middle', nameGap: gap } : {};

function axesOf(chart: TemplateChart, categories: string[], fmt: string) {
  const grid = {
    containLabel: true,
    left: 16,
    right: chart.legend === 'right' ? 140 : 16,
    top: (chart.title ? 40 : 16) + (chart.legend === 'top' ? 28 : 0),
    bottom: chart.legend === 'bottom' ? 40 : 16,
  };
  const value = (name: string, gap: number) => ({
    type: 'value',
    axisLabel: { formatter: fmt },
    ...named(name, gap),
  });
  if (chart.type === 'barHorizontal') {
    return {
      grid,
      xAxis: value(chart.axisX, 28),
      yAxis: { type: 'category', data: categories, inverse: true, ...named(chart.axisY, 48) },
    };
  }
  const right = chart.type === 'combo' && chart.series.some((s) => s.axis === 'right');
  return {
    grid,
    xAxis: { type: 'category', data: categories, ...named(chart.axisX, 28) },
    yAxis: right ? [value(chart.axisY, 48), value(chart.axisY2, 48)] : value(chart.axisY, 48),
  };
}

function cartesianSeries(chart: TemplateChart, s: SeriesData, fmt: string) {
  const kind =
    chart.type === 'combo'
      ? (s.source.kind ?? 'bar')
      : chart.type === 'line' || chart.type === 'area'
        ? 'line'
        : 'bar';
  const out: Record<string, unknown> = { type: kind, name: s.name, data: s.values };
  if (chart.stacked) out.stack = 'total';
  if (kind === 'line' && chart.smooth) out.smooth = true;
  if (chart.type === 'area') out.areaStyle = {};
  if (chart.type === 'combo' && s.source.axis === 'right') out.yAxisIndex = 1;
  if (s.source.color && chart.splitBy === null) out.itemStyle = { color: s.source.color };
  if (chart.labels)
    out.label = {
      show: true,
      position: chart.type === 'barHorizontal' ? 'right' : 'top',
      formatter: fmt,
    };
  return out;
}

function pieSeries(chart: TemplateChart, data: { categories: string[]; series: SeriesData[] }, fmt: string) {
  const s = data.series[0]!;
  const out: Record<string, unknown> = {
    type: 'pie',
    name: s.name,
    radius: chart.type === 'doughnut' ? ['40%', '70%'] : '70%',
    center: chart.legend === 'right' ? ['40%', '50%'] : ['50%', '50%'],
    data: data.categories.flatMap((name, i) => {
      const value = s.values[i];
      return value === null || value === undefined ? [] : [{ name, value }];
    }),
  };
  if (chart.labels) out.label = { show: true, formatter: fmt };
  return out;
}

/**
 * Описание ECharts графика конструктора по строкам запроса (§35.4): API (отчёт и предпросмотр) и вкладка «Графики».
 * Пустой результат — пустой график; нет колонки и больше 20 рядов из данных — ChartDataError.
 */
export function buildChartOption(chart: TemplateChart, rows: readonly unknown[]): ChartValue {
  const records = rows.filter(isRecord);
  requireColumns(chart, records);
  const data = chart.splitBy ? splitData(chart, records) : plainData(chart, records);
  const fmt = chartNumberRef(chart.number);
  const pie = isPie(chart.type);
  const option: Record<string, unknown> = {
    color: CHART_PALETTES[chart.palette],
    tooltip: { trigger: pie ? 'item' : 'axis', valueFormatter: fmt },
    legend: legendOf(chart),
  };
  if (chart.title) option.title = { text: chart.title, left: 'center' };
  if (pie) option.series = [pieSeries(chart, data, fmt)];
  else {
    Object.assign(option, axesOf(chart, data.categories, fmt));
    option.series = data.series.map((s) => cartesianSeries(chart, s, fmt));
  }
  return { type: 'echarts@v5', option };
}

import {
  buildChartOption,
  ChartDataError,
  type ChartValue,
  type TemplateChart,
  type TemplateQuery,
} from '@carbone-reports/shared';
import { AppError } from '../../lib/errors';

/** Ключ данных отчёта с описаниями графиков: `d.charts.<key>` (§35.4). */
export const CHARTS_DATA_KEY = 'charts';
export const CHARTS_KEY_TAKEN = 'ключ charts занят графиками';

export interface ChartIssue {
  path: string;
  message: string;
}

/** Проверки `PUT …/charts` сверх схемы: запрос есть и в режиме «Список строк»; ключ charts свободен. */
export function chartIssues(
  charts: readonly TemplateChart[],
  queries: readonly TemplateQuery[],
): ChartIssue[] {
  const issues: ChartIssue[] = [];
  const byKey = new Map(queries.map((q) => [q.key, q]));
  charts.forEach((c, i) => {
    const q = byKey.get(c.query);
    if (!q) issues.push({ path: `/${i}/query`, message: `нет запроса «${c.query}»` });
    else if (q.mode !== 'list')
      issues.push({
        path: `/${i}/query`,
        message: `запрос «${c.query}» возвращает одну строку — нужен режим «Список строк»`,
      });
  });
  if (charts.length > 0 && byKey.has(CHARTS_DATA_KEY))
    issues.push({ path: '', message: CHARTS_KEY_TAKEN });
  return issues;
}

/** Проверки `PUT …/queries` при графиках (R8): ключ charts, запросы графиков остаются списками. */
export function queryIssuesForCharts(
  queries: readonly TemplateQuery[],
  charts: readonly TemplateChart[],
): ChartIssue[] {
  if (charts.length === 0) return [];
  const issues: ChartIssue[] = [];
  queries.forEach((q, i) => {
    if (q.key === CHARTS_DATA_KEY) issues.push({ path: `/${i}/key`, message: CHARTS_KEY_TAKEN });
  });
  for (const c of charts) {
    const i = queries.findIndex((q) => q.key === c.query);
    if (i === -1)
      issues.push({ path: '', message: `запрос «${c.query}» используется графиком «${c.key}»` });
    else if (queries[i]!.mode !== 'list')
      issues.push({
        path: `/${i}/mode`,
        message: `запрос используется графиком «${c.key}» — нужен режим «Список строк»`,
      });
  }
  return issues;
}

export function assertNoIssues(issues: ChartIssue[]): void {
  if (issues.length) throw new AppError('VALIDATION', 400, 'неверные данные запроса', issues);
}

/**
 * `data.charts[key] = buildChartOption(...)` для каждого графика шаблона — в отчёте и предпросмотре.
 * Без графиков data не меняется. Ошибка данных графика — 400 CARBONE_TEMPLATE.
 */
export function injectCharts(
  data: Record<string, unknown>,
  charts: readonly TemplateChart[],
): Record<string, unknown> {
  if (charts.length === 0) return data;
  const out: Record<string, ChartValue> = {};
  for (const c of charts) {
    const rows = data[c.query];
    try {
      out[c.key] = buildChartOption(c, Array.isArray(rows) ? rows : []);
    } catch (e) {
      if (e instanceof ChartDataError)
        throw new AppError('CARBONE_TEMPLATE', 400, `ошибка шаблона: ${e.message}`);
      throw e;
    }
  }
  data[CHARTS_DATA_KEY] = out;
  return data;
}

import { type ChartValue, reviveChartFormatters } from '@carbone-reports/shared';
import { Text } from '@gravity-ui/uikit';
import * as echarts from 'echarts';
import { useEffect, useRef, useState } from 'react';

const WIDTH = 600;
const HEIGHT = 360;

/**
 * Предпросмотр графика конструктора (§35.5): ECharts в браузере (SVG), те же значения по умолчанию, что у сервера
 * (белый фон, без анимации, маркеры формата чисел — функции). Модуль грузится отдельным чанком (lazy в ChartsTab).
 */
export function ChartPreview({ value }: { value: ChartValue }) {
  const ref = useRef<HTMLDivElement>(null);
  const [error, setError] = useState<string | null>(null);
  useEffect(() => {
    if (!ref.current) return;
    const chart = echarts.init(ref.current, null, { renderer: 'svg', width: WIDTH, height: HEIGHT });
    try {
      chart.setOption({
        backgroundColor: '#ffffff',
        textStyle: { fontFamily: '"Noto Sans", sans-serif' },
        ...reviveChartFormatters(value.option),
        animation: false,
      });
      setError(null);
    } catch (e) {
      setError(e instanceof Error ? e.message : String(e));
    }
    return () => chart.dispose();
  }, [value]);
  return (
    <div className="cr-stack">
      <div
        ref={ref}
        data-testid="chart-preview"
        style={{ width: WIDTH, height: HEIGHT, border: '1px solid var(--g-color-line-generic)' }}
      />
      {error && <Text color="danger">Ошибка ECharts: {error}</Text>}
    </div>
  );
}

export const chartTag = (key: string) => `{d.charts.${key}:chart}`;

export function newChart(key: string, query: string): TemplateChart {
  return {
    key,
    query,
    type: 'bar',
    stacked: false,
    smooth: false,
    category: '',
    series: [{ column: '' }],
    splitBy: null,
    title: '',
    legend: 'bottom',
    labels: false,
    palette: 'default',
    number: { decimals: null, thousands: false, suffix: '' },
    axisX: '',
    axisY: '',
    axisY2: '',
  };
}

interface Draft {
  id: number;
  chart: TemplateChart;
}

/** Сравнение без учёта порядка ключей: jsonb в Postgres хранит ключи в своём порядке. */
const canon = (charts: TemplateChart[]) =>
  JSON.stringify(charts, (_k, v: unknown) =>
    v && typeof v === 'object' && !Array.isArray(v)
      ? Object.fromEntries(Object.entries(v).sort(([a], [b]) => (a < b ? -1 : a > b ? 1 : 0)))
      : v,
  );

/** Пустые необязательные поля ряда не хранятся. */
function cleanSeries(s: ChartSeries): ChartSeries {
  const out: ChartSeries = { column: s.column };
  if (s.name) out.name = s.name;
  if (s.color) out.color = s.color;
  if (s.kind) out.kind = s.kind;
  if (s.axis) out.axis = s.axis;
  return out;
}

/** Смена типа: поля, недопустимые для нового типа, сбрасываются (§35.3). */
function withType(c: TemplateChart, type: ChartType): TemplateChart {
  const pie = isPie(type);
  return {
    ...c,
    type,
    stacked: STACKABLE.includes(type) ? c.stacked : false,
    smooth: SMOOTHABLE.includes(type) ? c.smooth : false,
    splitBy: pie ? null : c.splitBy,
    axisY2: type === 'combo' ? c.axisY2 : '',
    series: (pie ? c.series.slice(0, 1) : c.series).map((s) =>
      cleanSeries(type === 'combo' ? s : { ...s, kind: undefined, axis: undefined }),
    ),
  };
}

function ColumnSelect({
  label,
  value,
  columns,
  known,
  empty,
  onChange,
}: {
  label: string;
  value: string;
  columns: string[];
  /** Запрос выполнялся — колонки известны. */
  known: boolean;
  /** Подпись пустого варианта; без неё колонка обязательна. */
  empty?: string;
  onChange: (v: string) => void;
}) {
  const missing = known && value !== '' && !columns.includes(value);
  const options = [
    ...(empty !== undefined ? [{ value: '', content: empty }] : []),
    ...columns.map((c) => ({ value: c, content: c })),
    ...(value !== '' && !columns.includes(value)
      ? [{ value, content: missing ? `${value} (нет в результате)` : value }]
      : []),
  ];
  return (
    <div className="cr-stack">
      <Select
        aria-label={label}
        value={value === '' && empty === undefined ? [] : [value]}
        options={options}
        onUpdate={([v]) => onChange(v ?? '')}
        placeholder="колонка"
        width="max"
      />
      {missing && <Text color="danger">Колонки «{value}» нет в результате запроса</Text>}
    </div>
  );
}

export function ChartsTab({ template, testParams }: TabProps) {
  const queryClient = useQueryClient();
  const { add } = useToaster();
  const copy = useCopy();
  const nextId = useRef(0);
  const makeDrafts = (t: TemplateAdminDetails): Draft[] =>
    t.charts.map((chart) => ({ id: nextId.current++, chart }));
  const [baseline, setBaseline] = useState(template);
  const [drafts, setDrafts] = useState<Draft[]>(() => makeDrafts(template));
  const [selectedId, setSelectedId] = useState<number | undefined>(drafts[0]?.id);
  const [runs, setRuns] = useState<Record<string, RunQueryResult>>({});
  const dirty = canon(drafts.map((d) => d.chart)) !== canon(baseline.charts);
  const selectedIdx = Math.max(
    0,
    drafts.findIndex((d) => d.id === selectedId),
  );
  const current = drafts[selectedIdx];
  const listQueries = template.queries.filter((q) => q.mode === 'list');

  const reseed = (t: TemplateAdminDetails) => {
    const next = makeDrafts(t);
    setBaseline(t);
    setDrafts(next);
    setSelectedId(next[Math.min(selectedIdx, next.length - 1)]?.id);
  };
  // Шаблон обновился на сервере: без несохранённых правок подхватываем, иначе сохраняем черновик.
  const stale = template.updatedAt !== baseline.updatedAt;
  if (stale && !dirty) reseed(template);

  // Тот же запуск, что на вкладке «Данные»: SQL сохранённого запроса на тестовых параметрах (§35.5).
  const run = useMutation({
    mutationFn: (key: string) => {
      const q = template.queries.find((x) => x.key === key);
      if (!q) throw new Error(`нет запроса «${key}»`);
      return api.templates.runQuery(template.id, {
        sql: q.sql,
        params: pickParams(template.params, testParams),
      });
    },
    onSuccess: (result, key) => setRuns((prev) => ({ ...prev, [key]: result })),
  });
  const save = useMutation({
    mutationFn: () =>
      api.templates.saveCharts(
        template.id,
        drafts.map((d) => d.chart),
      ),
    onSuccess: (t) => {
      applyTemplate(queryClient, t);
      reseed(t);
      add({ name: `tpl-charts-${Date.now()}`, title: 'Графики сохранены', theme: 'success' });
    },
  });

  const update = (patch: Partial<TemplateChart>) =>
    setDrafts((ds) =>
      ds.map((d, i) => (i === selectedIdx ? { ...d, chart: { ...d.chart, ...patch } } : d)),
    );
  const updateSeries = (n: number, patch: Partial<ChartSeries>) =>
    current &&
    update({
      series: current.chart.series.map((s, i) => (i === n ? cleanSeries({ ...s, ...patch }) : s)),
    });
  const addChart = () => {
    save.reset();
    let n = 1;
    while (drafts.some((d) => d.chart.key === `chart${n}`)) n++;
    const id = nextId.current++;
    setDrafts([...drafts, { id, chart: newChart(`chart${n}`, listQueries[0]?.key ?? '') }]);
    setSelectedId(id);
  };
  const removeChart = () => {
    save.reset();
    const next = drafts.filter((_, i) => i !== selectedIdx);
    setDrafts(next);
    setSelectedId(next[Math.max(0, selectedIdx - 1)]?.id);
  };
  const discard = () => {
    save.reset();
    reseed(template);
  };

  // Ошибки сервера приходят по позиции графика ('0.series.1.column').
  const errors = fieldErrors(save.error);
  const errorOf = (path: string) => errors[`${selectedIdx}.${path}`];
  const shown = Object.keys(errors).filter((k) => k.startsWith(`${selectedIdx}.`));
  const withErrors = new Set(Object.keys(errors).map((k) => k.split('.')[0]));

  const result = current ? runs[current.chart.query] : undefined;
  const columns = result?.columns ?? [];
  const preview = useMemo((): { value: ChartValue | null; error: string | null } => {
    if (!current || !result) return { value: null, error: null };
    const c = current.chart;
    if (!c.category || c.series.some((s) => !s.column))
      return { value: null, error: 'Выберите колонку подписей и колонки рядов' };
    try {
      return { value: buildChartOption(c, result.rows), error: null };
    } catch (e) {
      return { value: null, error: e instanceof Error ? e.message : String(e) };
    }
  }, [current, result]);

  const dirtyNote = dirty && (
    <>
      <Text color="warning">Есть несохранённые изменения</Text>
      <Button view="flat" onClick={discard}>
        Отменить
      </Button>
    </>
  );
  const c = current?.chart;

  return (
    <div
      style={{ display: 'grid', gridTemplateColumns: '240px 1fr', gap: 24, alignItems: 'start' }}
    >
      <div className="cr-stack">
        {drafts.map((d, i) => (
          <Button
            key={d.id}
            view={d.id === current?.id ? 'normal' : 'flat'}
            width="max"
            onClick={() => setSelectedId(d.id)}
          >
            {d.chart.key} <Label size="xs">{TYPE_OPTIONS.find((o) => o.value === d.chart.type)?.content}</Label>
            {withErrors.has(String(i)) && (
              <Label size="xs" theme="danger" title="В графике есть ошибки">
                <Icon data={CircleExclamation} size={12} />
                ошибка
              </Label>
            )}
          </Button>
        ))}
        <Button
          view="outlined"
          onClick={addChart}
          disabled={listQueries.length === 0 || drafts.length >= MAX_TEMPLATE_CHARTS}
        >
          <Icon data={Plus} />
          Добавить график
        </Button>
        {listQueries.length === 0 && (
          <Text color="secondary">
            Сначала добавьте запрос «Список строк» на вкладке «Данные» — график строится по его строкам.
          </Text>
        )}
      </div>
      <div className="cr-stack">
        {c ? (
          <>
            <div style={{ display: 'flex', gap: 12, alignItems: 'end', flexWrap: 'wrap' }}>
              <Field label="Ключ (в шаблоне — d.charts.ключ)" error={errorOf('key')}>
                <TextInput
                  value={c.key}
                  onUpdate={(v) => update({ key: v })}
                  controlProps={{ 'aria-label': 'Ключ графика' }}
                />
              </Field>
              <Field label="Запрос" error={errorOf('query')}>
                <Select
                  aria-label="Запрос"
                  value={c.query ? [c.query] : []}
                  options={listQueries.map((q) => ({ value: q.key, content: q.key }))}
                  onUpdate={([v]) => v && update({ query: v })}
                  width={200}
                />
              </Field>
              <Field label="Тип" error={errorOf('type')}>
                <Select
                  aria-label="Тип графика"
                  value={[c.type]}
                  options={TYPE_OPTIONS}
                  onUpdate={([v]) => v && current && update(withType(current.chart, v as ChartType))}
                  width={240}
                />
              </Field>
              <Button view="flat-danger" onClick={removeChart}>
                <Icon data={TrashBin} />
                Удалить график
              </Button>
            </div>
            <Card view="outlined" style={{ padding: 12 }} className="cr-stack">
              <div style={{ display: 'flex', gap: 8, alignItems: 'center' }}>
                <Text variant="subheader-1">Данные</Text>
                <Button
                  size="s"
                  onClick={() => run.mutate(c.query)}
                  loading={run.isPending}
                  disabled={!c.query}
                >
                  <Icon data={Play} />
                  Выполнить запрос
                </Button>
                {!result && (
                  <Text color="secondary">Колонки появятся после выполнения запроса на тестовых параметрах.</Text>
                )}
              </div>
              <Field label="Подписи (категории)" error={errorOf('category')}>
                <ColumnSelect
                  label="Подписи (категории)"
                  value={c.category}
                  columns={columns}
                  known={!!result}
                  onChange={(v) => update({ category: v })}
                />
              </Field>
              {!isPie(c.type) && (
                <Field label="Ряды из данных (колонка с названиями рядов)" error={errorOf('splitBy')}>
                  <ColumnSelect
                    label="Ряды из данных"
                    value={c.splitBy ?? ''}
                    columns={columns}
                    known={!!result}
                    empty="— нет —"
                    onChange={(v) =>
                      update({
                        splitBy: v || null,
                        series: v ? [cleanSeries({ ...c.series[0]!, color: undefined })] : c.series,
                      })
                    }
                  />
                </Field>
              )}
              {c.series.map((s, n) => (
                <div key={n} style={{ display: 'flex', gap: 8, alignItems: 'end', flexWrap: 'wrap' }}>
                  <Field label={c.splitBy ? 'Значения' : `Ряд ${n + 1}`} error={errorOf(`series.${n}.column`)}>
                    <ColumnSelect
                      label={`Колонка ряда ${n + 1}`}
                      value={s.column}
                      columns={columns}
                      known={!!result}
                      onChange={(v) => updateSeries(n, { column: v })}
                    />
                  </Field>
                  {!c.splitBy && (
                    <Field label="Название" error={errorOf(`series.${n}.name`)}>
                      <TextInput
                        value={s.name ?? ''}
                        placeholder={s.column}
                        onUpdate={(v) => updateSeries(n, { name: v })}
                        controlProps={{ 'aria-label': `Название ряда ${n + 1}` }}
                      />
                    </Field>
                  )}
                  {!c.splitBy && (
                    <Field label="Цвет" error={errorOf(`series.${n}.color`)}>
                      <TextInput
                        value={s.color ?? ''}
                        placeholder="#RRGGBB"
                        onUpdate={(v) => updateSeries(n, { color: v })}
                        controlProps={{ 'aria-label': `Цвет ряда ${n + 1}` }}
                      />
                    </Field>
                  )}
                  {c.type === 'combo' && (
                    <Select
                      aria-label={`Вид ряда ${n + 1}`}
                      value={[s.kind ?? 'bar']}
                      options={[
                        { value: 'bar', content: 'Столбцы' },
                        { value: 'line', content: 'Линия' },
                      ]}
                      onUpdate={([v]) => updateSeries(n, { kind: v as 'bar' | 'line' })}
                    />
                  )}
                  {c.type === 'combo' && (
                    <Select
                      aria-label={`Ось ряда ${n + 1}`}
                      value={[s.axis ?? 'left']}
                      options={[
                        { value: 'left', content: 'Левая ось' },
                        { value: 'right', content: 'Правая ось' },
                      ]}
                      onUpdate={([v]) => updateSeries(n, { axis: v as 'left' | 'right' })}
                    />
                  )}
                  {c.series.length > 1 && (
                    <Button
                      view="flat-danger"
                      aria-label={`Удалить ряд ${n + 1}`}
                      onClick={() => update({ series: c.series.filter((_, i) => i !== n) })}
                    >
                      <Icon data={TrashBin} />
                    </Button>
                  )}
                </div>
              ))}
              {errorOf('series') && <Text color="danger">{errorOf('series')}</Text>}
              {!isPie(c.type) && !c.splitBy && c.series.length < MAX_CHART_SERIES && (
                <Button view="outlined" onClick={() => update({ series: [...c.series, { column: '' }] })}>
                  <Icon data={Plus} />
                  Добавить ряд
                </Button>
              )}
            </Card>
            <Card view="outlined" style={{ padding: 12 }} className="cr-stack">
              <Text variant="subheader-1">Оформление</Text>
              <div style={{ display: 'flex', gap: 12, flexWrap: 'wrap', alignItems: 'end' }}>
                <Field label="Заголовок" error={errorOf('title')}>
                  <TextInput
                    value={c.title}
                    onUpdate={(v) => update({ title: v })}
                    controlProps={{ 'aria-label': 'Заголовок графика' }}
                  />
                </Field>
                <Field label="Легенда">
                  <Select
                    aria-label="Легенда"
                    value={[c.legend]}
                    options={LEGEND_OPTIONS}
                    onUpdate={([v]) => v && update({ legend: v as TemplateChart['legend'] })}
                  />
                </Field>
                <Field label="Палитра">
                  <Select
                    aria-label="Палитра"
                    value={[c.palette]}
                    options={PALETTE_OPTIONS}
                    onUpdate={([v]) => v && update({ palette: v as TemplateChart['palette'] })}
                  />
                </Field>
              </div>
              {!isPie(c.type) && (
                <div style={{ display: 'flex', gap: 12, flexWrap: 'wrap', alignItems: 'end' }}>
                  <Field label="Ось X" error={errorOf('axisX')}>
                    <TextInput
                      value={c.axisX}
                      onUpdate={(v) => update({ axisX: v })}
                      controlProps={{ 'aria-label': 'Название оси X' }}
                    />
                  </Field>
                  <Field label="Ось Y" error={errorOf('axisY')}>
                    <TextInput
                      value={c.axisY}
                      onUpdate={(v) => update({ axisY: v })}
                      controlProps={{ 'aria-label': 'Название оси Y' }}
                    />
                  </Field>
                  {c.type === 'combo' && (
                    <Field label="Правая ось Y" error={errorOf('axisY2')}>
                      <TextInput
                        value={c.axisY2}
                        onUpdate={(v) => update({ axisY2: v })}
                        controlProps={{ 'aria-label': 'Название правой оси Y' }}
                      />
                    </Field>
                  )}
                </div>
              )}
              <div style={{ display: 'flex', gap: 16, flexWrap: 'wrap', alignItems: 'end' }}>
                {STACKABLE.includes(c.type) && (
                  <Checkbox checked={c.stacked} onUpdate={(v) => update({ stacked: v })}>
                    Накопление
                  </Checkbox>
                )}
                {SMOOTHABLE.includes(c.type) && (
                  <Checkbox checked={c.smooth} onUpdate={(v) => update({ smooth: v })}>
                    Сглаживание линий
                  </Checkbox>
                )}
                <Checkbox checked={c.labels} onUpdate={(v) => update({ labels: v })}>
                  Подписи значений
                </Checkbox>
              </div>
              <div style={{ display: 'flex', gap: 12, flexWrap: 'wrap', alignItems: 'end' }}>
                <Field label="Знаков после запятой" error={errorOf('number.decimals')}>
                  <Select
                    aria-label="Знаков после запятой"
                    value={[c.number.decimals === null ? '' : String(c.number.decimals)]}
                    options={DECIMALS_OPTIONS}
                    onUpdate={([v]) =>
                      update({ number: { ...c.number, decimals: v ? Number(v) : null } })
                    }
                  />
                </Field>
                <Checkbox
                  checked={c.number.thousands}
                  onUpdate={(v) => update({ number: { ...c.number, thousands: v } })}
                >
                  Разделять тысячи
                </Checkbox>
                <Field label="Суффикс (₽, %, шт.)" error={errorOf('number.suffix')}>
                  <TextInput
                    value={c.number.suffix}
                    onUpdate={(v) => update({ number: { ...c.number, suffix: v } })}
                    controlProps={{ 'aria-label': 'Суффикс чисел' }}
                  />
                </Field>
              </div>
            </Card>
            <Card view="outlined" style={{ padding: 12 }} className="cr-stack">
              <Text variant="subheader-1">Предпросмотр</Text>
              {preview.value ? (
                <Suspense fallback={<Loader />}>
                  <ChartPreview value={preview.value} />
                </Suspense>
              ) : (
                <Text color={preview.error ? 'danger' : 'secondary'}>
                  {preview.error ?? 'Выполните запрос, чтобы увидеть график на тестовых данных.'}
                </Text>
              )}
              <div style={{ display: 'flex', gap: 8, alignItems: 'center' }}>
                <Text variant="code-1">{chartTag(c.key)}</Text>
                <Button size="s" onClick={() => void copy(chartTag(c.key))} aria-label="Скопировать тег">
                  <Icon data={Copy} />
                  Скопировать
                </Button>
              </div>
              <Text color="secondary">
                Вставьте в документ картинку-заглушку, а тег — в её замещающий текст. Размер картинки — размер
                графика.
              </Text>
            </Card>
          </>
        ) : (
          <Text color="secondary">Графиков нет — добавьте первый.</Text>
        )}
        <div style={{ display: 'flex', gap: 8, alignItems: 'center' }}>
          <Button view="action" onClick={() => save.mutate()} loading={save.isPending} disabled={!dirty}>
            Сохранить графики
          </Button>
          {dirty && stale && (
            <Text color="warning">Шаблон изменился на сервере — сохранение перезапишет изменения</Text>
          )}
          {dirtyNote}
        </div>
        <GeneralError error={save.error} errors={errors} shown={shown} />
        <ErrorAlert error={run.error} />
      </div>
    </div>
  );
}
