# 2.7.0: PDF — PDF/A, водяной знак, нумерация, метаданные, приложенные файлы — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PDF отчёта (предпросмотр, формирование, скачивание) собирается с настройками шаблона: PDF/A-2b (через OnlyOffice `outputtype: pdfa`), водяной знак, сквозная нумерация страниц, метаданные (Info + XMP) и постоянные PDF-файлы шаблона в начале и в конце; настройки и приложения редактируются на вкладке «PDF» и переносятся между средами.

**Architecture:** Чистая обработка готового PDF — `apps/api/src/modules/pdf/postprocess.ts` (`pdf-lib` + `@pdf-lib/fontkit`, шрифт Noto Sans Regular из `packages/carbone/assets/fonts`), выполняется в пуле рабочих потоков рендера как задача вида `pdf` (`RenderJob.kind`). Оркестрация в главном потоке — `apps/api/src/modules/pdf/finish.ts`: подстановка тегов `{d.…}` (`fillPdfText` из `packages/shared`), чтение приложений из хранилища, вызов `deps.pdf` (обработчик на пуле), лимит 100 МБ. `renderReport` получает настройки шаблона: при `pdfa` конвертер вызывается с `outputtype: 'pdfa'`, затем — обработка, если есть водяной знак, нумерация, метаданные или приложения. Хранение: колонка `templates.pdf_options` и таблица `template_attachments` (миграция 0008), файлы приложений — `templates/<id>/attachments/<uuid>.pdf`.

**Tech Stack:** Node 22, TypeScript, zod 4, vitest; Fastify 5 + drizzle-orm/drizzle-kit (Postgres); `pdf-lib =1.17.1` (MIT), `@pdf-lib/fontkit =1.1.1` (MIT); `unpdf =1.8.1` (MIT, только тесты — извлечение текста); React 19 + Gravity UI; OnlyOffice Document Server 9.4.0.1 и veraPDF `verapdf/cli:v1.30.3` — только в интеграционном тесте CI.

**Spec:** `docs/superpowers/specs/2026-10-02-carbone-reports-design.md`, §36 (и §30 — очередь выпусков, §24.2 — снимок запуска, §33 — перенос шаблонов, §35 — образец R8 с блокировкой строки шаблона).

## Решения контроллера (там, где спецификация молчит)

- R1. Выключенный блок настроек — отсутствующий ключ (`watermark`, `pageNumbers`, `metadata`); `pdfa` — `false` по умолчанию. `metadata`, у которой все четыре поля пустые, API не хранит (`normalizePdfOptions`).
- R2. Тексты подставляются и очищаются в главном потоке (`buildPdfJob`): управляющие символы → пробел, символы вне шрифта → `?` — для всех текстовых полей (водяной знак, метаданные); поток пула очищает водяной знак ещё раз. Даты — `Date` → `toISOString()`.
- R3. Метаданные: при обработке Info `Producer` = `carbone-reports`, `CreationDate` и `ModDate` = момент сборки (`job.now`); XMP пишется всегда при обработке и строится из итогового Info (Title, Author, Subject, Keywords, Creator, Producer, даты) — так Info и XMP совпадают и при PDF/A; при `pdfa` добавляются `pdfaid:part=2`, `pdfaid:conformance=B`. Поток метаданных — без `Filter` (требование PDF/A-2).
- R4. Сохранение PDF — `useObjectStreams: false`; `/ID` трейлера и `OutputIntents` каталога сохраняются (база — документ отчёта, страницы приложений копируются в него).
- R5. Проверка приложения при загрузке — в главном потоке (`inspectPdf`, файл ≤ 20 МБ, только администратор).
- R6. `PATCH …/attachments/:aid` `{ placement?, sortOrder? }`: `sortOrder` — целевая позиция (с 0) в группе `placement`; без `sortOrder` — в конец группы; обе группы перенумеровываются подряд с 0.
- R7. Копия шаблона («Дублировать») копирует настройки PDF и приложения (файлы копируются под новый идентификатор).
- R8. PDF прошлых запусков не пересобирается: `out.pdf` пишется обработанным при создании запуска; `ensureRunFile` для `pdf` (запуск без готового PDF) собирает без настроек PDF, как в 2.6.0.
- R9. Ошибки: потока пула при обработке — `502 PDF_ERROR` «ошибка обработки PDF: …»; срок — `504 TIMEOUT`; итог > 100 МБ — `400 BAD_REQUEST` «итоговый PDF больше 100 МБ»; приложение не читается из хранилища — `502 STORAGE_ERROR` «приложенный файл «{name}» недоступен».
- R10. Справка — раздел `pdf` с одним проверяемым примером (тег в документе даёт тот же текст, что в поле PDF), основное — во вступлении.

```ts
import { z } from 'zod';

// Модуль не импортирует ./index: index реэкспортирует его и использует схемы в TemplateAdminDetails.

// ---- Настройки PDF шаблона (§36) ----

export const MAX_PDF_ATTACHMENTS = 10;
export const MAX_PDF_ATTACHMENT_BYTES = 20 * 1024 * 1024;
/** Страниц во всех приложенных файлах шаблона. */
export const MAX_PDF_ATTACHMENT_PAGES = 500;
export const MAX_PDF_RESULT_BYTES = 100 * 1024 * 1024;
export const PDF_PAGE_FORMAT_DEFAULT = 'Стр. {page} из {pages}';

export const PdfColor = z.enum(['gray', 'red', 'blue']);
export type PdfColor = z.infer<typeof PdfColor>;
export const PDF_COLORS: Record<PdfColor, string> = {
  gray: '#808080',
  red: '#C00000',
  blue: '#1F4E9A',
};

export const PdfWatermark = z.strictObject({
  text: z.string().trim().min(1, 'укажите текст').max(200),
  opacity: z.number().int().min(10).max(50).default(20),
  color: PdfColor.default('gray'),
  angle: z.enum(['diagonal', 'horizontal']).default('diagonal'),
});
export type PdfWatermark = z.infer<typeof PdfWatermark>;

export const PdfPosition = z.enum(['bottom-center', 'bottom-right', 'top-right']);
export type PdfPosition = z.infer<typeof PdfPosition>;

export const PdfPageNumbers = z.strictObject({
  format: z
    .string()
    .trim()
    .min(1)
    .max(100)
    .refine((s) => s.includes('{page}'), 'нужен {page} — номер страницы')
    .default(PDF_PAGE_FORMAT_DEFAULT),
  position: PdfPosition.default('bottom-center'),
  skipFirst: z.boolean().default(false),
});
export type PdfPageNumbers = z.infer<typeof PdfPageNumbers>;

const MetaText = z.string().trim().max(500).default('');
export const PdfMetadata = z.strictObject({
  title: MetaText,
  author: MetaText,
  subject: MetaText,
  keywords: MetaText,
});
export type PdfMetadata = z.infer<typeof PdfMetadata>;

/** Выключенный блок — отсутствующий ключ (R1). */
export const PdfOptions = z.strictObject({
  pdfa: z.boolean().default(false),
  watermark: PdfWatermark.optional(),
  pageNumbers: PdfPageNumbers.optional(),
  metadata: PdfMetadata.optional(),

const TAG_RE = /\{d\.([^{}]*)\}/g;
const PATH_RE = /^[A-Za-z_]\w*(?:\.[A-Za-z_]\w*|\[\d+\])*$/;
const SEGMENT_RE = /([A-Za-z_]\w*)|\[(\d+)\]/g;

function resolvePath(data: unknown, path: string): unknown {
  let cur = data;
  for (const [, key, index] of path.matchAll(SEGMENT_RE)) {
    if (cur === null || typeof cur !== 'object') return undefined;
    if (key !== undefined) {
      if (Array.isArray(cur) || !Object.hasOwn(cur, key)) return undefined;
      cur = (cur as Record<string, unknown>)[key];
    } else {
      if (!Array.isArray(cur)) return undefined;
      cur = cur[Number(index)];
    }
  }
  return cur;
}

/** Подставляет простые пути `{d.a.b}`, `{d.items[0].name}`; прочие теги остаются как есть. */
export function fillPdfText(text: string, data: unknown): string {
  return text.replace(TAG_RE, (whole, path: string) => {
    if (!PATH_RE.test(path)) return whole;
    const v = resolvePath(data, path);
    if (typeof v === 'string') return v;
    if (typeof v === 'number' || typeof v === 'boolean') return String(v);
    if (v instanceof Date) return v.toISOString();
    return '';
  });
}

/** Ошибка у поля при сохранении: тег с форматтером, циклом или неверным путём. */
export function pdfTextIssues(text: string): string | null {
  for (const m of text.matchAll(TAG_RE)) {
    if (!PATH_RE.test(m[1]!)) return `в полях PDF теги без форматтеров: ${m[0]}`;
  }
  return null;
}

/** Постоянная часть текста — без тегов `{d.…}`. */
export function pdfStaticText(text: string): string {
  return text.replace(TAG_RE, '');
```

```ts
import { decodePDFRawStream, PDFDocument, PDFName, PDFRawStream } from 'pdf-lib';

/** Файл не подходит как приложение: текст — для пользователя. */
export class PdfInputError extends Error {}

const PDFAID_RE = /pdfaid:part\s*(?:=\s*["']\s*[1-4]|>\s*[1-4]\s*<)/;

/** XMP каталога (без фильтра или с FlateDecode); нет — null. */
export function readXmp(doc: PDFDocument): string | null {
  const ref = doc.catalog.get(PDFName.of('Metadata'));
  const stream = ref ? doc.context.lookup(ref) : undefined;
  if (!(stream instanceof PDFRawStream)) return null;
  return new TextDecoder().decode(decodePDFRawStream(stream).decode());
}

/** Проверка приложенного файла (§36.3): PDF, не повреждён, без шифрования; страницы и заявленный PDF/A. */
export async function inspectPdf(data: Uint8Array): Promise<{ pages: number; pdfa: boolean }> {
  if (Buffer.from(data.subarray(0, 5)).toString('latin1') !== '%PDF-') {
    throw new PdfInputError('файл не PDF');
  }
  let doc: PDFDocument;
  try {
    doc = await PDFDocument.load(data, { ignoreEncryption: true, updateMetadata: false });
  } catch {
    throw new PdfInputError('PDF повреждён');
  }
  if (doc.isEncrypted) throw new PdfInputError('PDF защищён паролем');
  const pages = doc.getPageCount();
  if (pages === 0) throw new PdfInputError('PDF повреждён');
  let xmp: string | null = null;
  try {
    xmp = readXmp(doc);
  } catch {
    xmp = null;
  }
  return { pages, pdfa: xmp !== null && PDFAID_RE.test(xmp) };
}
```

```ts
import fontkit from '@pdf-lib/fontkit';
import { PDF_COLORS, type PdfColor, type PdfPlacement, type PdfPosition } from '@carbone-reports/shared';
import { degrees, PDFDocument, PDFName, rgb, type PDFFont, type PDFPage } from 'pdf-lib';
import { pdfFontBytes, sanitizePdfText } from './font';

export const PDF_PRODUCER = 'carbone-reports';

export interface PdfPostJob {
  pdfa: boolean;
  watermark: {
    text: string;
    opacity: number;
    color: PdfColor;
    angle: 'diagonal' | 'horizontal';
  } | null;
  pageNumbers: { format: string; position: PdfPosition; skipFirst: boolean } | null;
  /** Значения уже подставлены; пустая строка — поле не меняется (title пустым не бывает). */
  metadata: { title: string; author: string; subject: string; keywords: string } | null;
  /** В порядке итогового документа: start по порядку, затем end по порядку. */
  attachments: { placement: PdfPlacement; data: Uint8Array }[];
  /** Момент сборки, ISO — CreationDate/ModDate и даты XMP (R3). */
  now: string;
}

const WATERMARK_SHARE = 0.8;
const WATERMARK_MAX_SIZE = 120;
const WATERMARK_MIN_SIZE = 6;
const NUMBER_SIZE = 9;
const NUMBER_COLOR = '#404040';
const NUMBER_MARGIN = 24;

const hex = (h: string) =>
  rgb(
    parseInt(h.slice(1, 3), 16) / 255,
    parseInt(h.slice(3, 5), 16) / 255,
    parseInt(h.slice(5, 7), 16) / 255,
  );

export interface VisualView {
  box: { x: number; y: number; width: number; height: number };
  rot: 0 | 90 | 180 | 270;
  /** Ширина и высота страницы так, как её видит читатель. */
  w: number;
  h: number;
}

/** Видимая область: CropBox (иначе MediaBox) с учётом /Rotate (по часовой стрелке). */
export function visualView(page: PDFPage): VisualView {
  const box = page.getCropBox();
  const rot = ((((Math.round(page.getRotation().angle / 90) * 90) % 360) + 360) % 360) as VisualView['rot'];
  const turned = rot === 90 || rot === 270;
  return { box, rot, w: turned ? box.height : box.width, h: turned ? box.width : box.height };
}

/** Точка видимой страницы (u — вправо, v — вверх от левого нижнего угла) → координаты страницы. */
export function toPage(v: VisualView, u: number, w: number): { x: number; y: number } {
  const { x, y, width, height } = v.box;
  switch (v.rot) {
    case 90:
      return { x: x + width - w, y: y + u };
    case 180:
      return { x: x + width - u, y: y + height - w };
    case 270:
      return { x: x + w, y: y + height - u };
    default:
      return { x: x + u, y: y + w };
  }
}

function drawWatermark(page: PDFPage, font: PDFFont, text: string, wm: NonNullable<PdfPostJob['watermark']>) {
  const v = visualView(page);
  const phi = wm.angle === 'diagonal' ? Math.atan2(v.h, v.w) : 0;
  const span = wm.angle === 'diagonal' ? Math.hypot(v.w, v.h) : v.w;
  const size = Math.min(
    WATERMARK_MAX_SIZE,
    Math.max(WATERMARK_MIN_SIZE, (span * WATERMARK_SHARE) / font.widthOfTextAtSize(text, 1)),
  );
  const tw = font.widthOfTextAtSize(text, size);
  const th = font.heightAtSize(size, { descender: false });
  // Начало строки — так, чтобы центр строки совпал с центром видимой страницы.
  const u = v.w / 2 - (tw / 2) * Math.cos(phi) + (th / 2) * Math.sin(phi);
  const w = v.h / 2 - (tw / 2) * Math.sin(phi) - (th / 2) * Math.cos(phi);
  const p = toPage(v, u, w);
  page.drawText(text, {
    x: p.x,
    y: p.y,
    size,
    font,
    color: hex(PDF_COLORS[wm.color]),
    opacity: wm.opacity / 100,
    rotate: degrees((phi * 180) / Math.PI + v.rot),
  });
}

function drawPageNumber(page: PDFPage, font: PDFFont, text: string, position: PdfPosition) {
  const v = visualView(page);
  const tw = font.widthOfTextAtSize(text, NUMBER_SIZE);
  const th = font.heightAtSize(NUMBER_SIZE, { descender: false });
  const u = position === 'bottom-center' ? (v.w - tw) / 2 : v.w - NUMBER_MARGIN - tw;
  const w = position === 'top-right' ? v.h - NUMBER_MARGIN - th : NUMBER_MARGIN;
  const p = toPage(v, u, w);
  page.drawText(text, {
    x: p.x,
    y: p.y,
    size: NUMBER_SIZE,
    font,
    color: hex(NUMBER_COLOR),
    rotate: degrees(v.rot),
  });
}

function writeInfo(doc: PDFDocument, job: PdfPostJob): void {
  const m = job.metadata;
  if (m) {
    if (m.title) doc.setTitle(sanitizePdfText(m.title));
    if (m.author) doc.setAuthor(sanitizePdfText(m.author));
    if (m.subject) doc.setSubject(sanitizePdfText(m.subject));
    if (m.keywords) doc.setKeywords([sanitizePdfText(m.keywords)]);
  }
  const now = new Date(job.now);
  doc.setProducer(PDF_PRODUCER);
  doc.setCreationDate(now);
  doc.setModificationDate(now);
}

const esc = (s: string) =>
  s.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;');
/** Info хранит даты с точностью до секунды — XMP так же (R3). */
const xmpDate = (d: Date) => d.toISOString().replace(/\.\d{3}Z$/, 'Z');

/** XMP из итогового Info: при PDF/A значения Info и XMP обязаны совпадать (R3). */
function writeXmp(doc: PDFDocument, pdfa: boolean): void {
  const lines: string[] = ['<dc:format>application/pdf</dc:format>'];
  const title = doc.getTitle();
  const author = doc.getAuthor();
  const subject = doc.getSubject();
  const keywords = doc.getKeywords();
  const creator = doc.getCreator();
  const producer = doc.getProducer();
  const created = doc.getCreationDate();
  const modified = doc.getModificationDate();
  if (title)
    lines.push(`<dc:title><rdf:Alt><rdf:li xml:lang="x-default">${esc(title)}</rdf:li></rdf:Alt></dc:title>`);
  if (author) lines.push(`<dc:creator><rdf:Seq><rdf:li>${esc(author)}</rdf:li></rdf:Seq></dc:creator>`);
  if (subject)
    lines.push(
      `<dc:description><rdf:Alt><rdf:li xml:lang="x-default">${esc(subject)}</rdf:li></rdf:Alt></dc:description>`,
    );
  if (keywords) lines.push(`<pdf:Keywords>${esc(keywords)}</pdf:Keywords>`);
  if (producer) lines.push(`<pdf:Producer>${esc(producer)}</pdf:Producer>`);
  if (creator) lines.push(`<xmp:CreatorTool>${esc(creator)}</xmp:CreatorTool>`);
  if (created) lines.push(`<xmp:CreateDate>${xmpDate(created)}</xmp:CreateDate>`);
  if (modified) lines.push(`<xmp:ModifyDate>${xmpDate(modified)}</xmp:ModifyDate>`);
  if (pdfa) lines.push('<pdfaid:part>2</pdfaid:part>', '<pdfaid:conformance>B</pdfaid:conformance>');
  const xml =
    '<?xpacket begin="﻿" id="W5M0MpCehiHzreSzNTczkc9d"?>\n' +
    '<x:xmpmeta xmlns:x="adobe:ns:meta/">\n' +
    '<rdf:RDF xmlns:rdf="http://www.w3.org/1999/02/22-rdf-syntax-ns#">\n' +
    '<rdf:Description rdf:about=""' +
    ' xmlns:dc="http://purl.org/dc/elements/1.1/"' +
    ' xmlns:xmp="http://ns.adobe.com/xap/1.0/"' +
    ' xmlns:pdf="http://ns.adobe.com/pdf/1.3/"' +
    ' xmlns:pdfaid="http://www.aiim.org/pdfa/ns/id/">\n' +
    lines.join('\n') +
    '\n</rdf:Description>\n</rdf:RDF>\n</x:xmpmeta>\n<?xpacket end="w"?>';
  // Без Filter: поток метаданных PDF/A-2 не сжимается. Строка — в UTF-8 (pdf-lib пишет строку побайтно).
  const stream = doc.context.stream(new TextEncoder().encode(xml), { Type: 'Metadata', Subtype: 'XML' });
  doc.catalog.set(PDFName.of('Metadata'), doc.context.register(stream));
}

/**
 * Итоговый PDF (§36.4): приложения, водяной знак, нумерация, Info и XMP. База — документ отчёта:
 * его OutputIntents и /ID трейлера сохраняются (R4).
 */
export async function postprocessPdf(pdf: Uint8Array, job: PdfPostJob): Promise<Uint8Array> {
  const doc = await PDFDocument.load(pdf, { updateMetadata: false });
  let at = 0;
  for (const a of job.attachments) {
    const src = await PDFDocument.load(a.data, { updateMetadata: false });
    const pages = await doc.copyPages(src, src.getPageIndices());
    for (const p of pages) {
      if (a.placement === 'start') doc.insertPage(at++, p);
      else doc.addPage(p);
    }
  }
  const watermark = job.watermark ? sanitizePdfText(job.watermark.text).trim() : '';
  if (watermark || job.pageNumbers) {
    doc.registerFontkit(fontkit);
    const font = await doc.embedFont(pdfFontBytes(), { subset: true });
    const pages = doc.getPages();
    if (watermark) for (const p of pages) drawWatermark(p, font, watermark, job.watermark!);
    const pn = job.pageNumbers;
    if (pn) {
      pages.forEach((p, i) => {
        if (pn.skipFirst && i === 0) return;
        const text = sanitizePdfText(
          pn.format.replaceAll('{page}', String(i + 1)).replaceAll('{pages}', String(pages.length)),
        );
        drawPageNumber(p, font, text, pn.position);
      });
    }
  }
  writeInfo(doc, job);
  writeXmp(doc, job.pdfa);
  return doc.save({ useObjectStreams: false });
}
```

```ts
// Поток пула рендера: собирает отчёт встроенной сборкой Carbone (формат шаблона) или обрабатывает
// готовый PDF (§36.4, задача kind = pdf). Глобальные carbone.set()/reset() не вызываем: lang, timezone
// и настройки загрузки изображений всегда приходят в options. Предупреждения рендера (R6) уходят пулу.
import { parentPort } from 'node:worker_threads';
import carbone from '@carbone-reports/carbone';
import { postprocessPdf, type PdfPostJob } from '../pdf/postprocess';
import type { RenderOptions } from './pool';

interface Request {
  id: number;
  kind?: 'carbone' | 'pdf';
  template: Uint8Array;
  ext: string;
  data: string;
  options: RenderOptions;
  extra?: Uint8Array[];
}

type PdfJobData = Omit<PdfPostJob, 'attachments'> & {
  attachments: { placement: PdfPostJob['attachments'][number]['placement'] }[];
};

const port = parentPort;
if (!port) throw new Error('worker.ts запускается только как поток пула рендера');

async function handle(m: Request): Promise<{ buffer: Uint8Array; warnings: string[] }> {
  const template = Buffer.from(m.template.buffer, m.template.byteOffset, m.template.byteLength);
  if (m.kind === 'pdf') {
    const job = JSON.parse(m.data) as PdfJobData;
    const extra = m.extra ?? [];
    const buffer = await postprocessPdf(template, {
      ...job,
      attachments: job.attachments.map((a, i) => ({ placement: a.placement, data: extra[i]! })),
    });
    return { buffer, warnings: [] };
  }
  return carbone.renderBufferWithWarnings(template, m.ext, JSON.parse(m.data), m.options);
}

port.on('message', (m: Request) => {
  handle(m).then(
    ({ buffer: out, warnings }) => {
      // Передаём ArrayBuffer без копии, если буфер занимает его целиком; иначе копируем.
      const ab = out.buffer;
      const whole =
        ab instanceof ArrayBuffer && out.byteOffset === 0 && out.byteLength === ab.byteLength;
      const bytes = whole ? new Uint8Array(ab, 0, out.byteLength) : new Uint8Array(out);
```

```ts
import type { PdfPostprocessor } from '../../deps';
import { AppError } from '../../lib/errors';
import { RenderTimeoutError, TemplateRenderError, type RenderPool } from '../render/pool';
import { postprocessPdf } from './postprocess';

const failed = (message: string, cause?: unknown) =>
  new AppError('PDF_ERROR', 502, `ошибка обработки PDF: ${message}`, undefined, cause);

/** Обработка PDF задачей пула рендера: тяжёлая работа не блокирует главный поток (§36.4). */
export function createPoolPdfPostprocessor(pool: Pick<RenderPool, 'run'>): PdfPostprocessor {
  return async (pdf, job, timeoutMs) => {
    const { attachments, ...rest } = job;
    try {
      const r = await pool.run(
        {
          kind: 'pdf',
          template: pdf,
          ext: 'pdf',
          data: { ...rest, attachments: attachments.map((a) => ({ placement: a.placement })) },
          options: { lang: '', timezone: '' },
          extra: attachments.map((a) => a.data),
        },
        Date.now() + timeoutMs,
      );
      return r.out;
    } catch (e) {
      if (e instanceof RenderTimeoutError)
        throw new AppError('TIMEOUT', 504, 'превышено время ожидания');
      if (e instanceof TemplateRenderError) throw failed(e.message);
      throw failed('поток рендера недоступен', e);
    }
  };
}

/** В этом потоке — для тестов API (createTestApp) и инструментов без пула. */
export const inProcessPdfPostprocessor: PdfPostprocessor = async (pdf, job) => {
  try {
    return Buffer.from(await postprocessPdf(pdf, job));
  } catch (e) {
    throw failed(e instanceof Error ? e.message : String(e));
  }
};
```

```ts
/** veraPDF в контейнере: соответствие PDF/A-2B и нарушенные правила (для журнала CI). */
async function verapdf(pdf: Buffer): Promise<{ compliant: boolean; failed: string }> {
  const c = await new GenericContainer(VERAPDF_IMAGE)
    .withPlatform('linux/amd64')
    .withCopyContentToContainer([{ content: pdf, target: '/data/out.pdf' }])
    .withCommand([...VERAPDF_ARGS, '/data/out.pdf'])
    .withWaitStrategy(Wait.forOneShotStartup())
    .withStartupTimeout(180_000)
    .start();
  const chunks: string[] = [];
  const stream = await c.logs();
  await new Promise<void>((resolve) => {
    const timer = setTimeout(resolve, 10_000);
    const done = () => (clearTimeout(timer), resolve());
    stream.on('data', (ch: Buffer | string) => chunks.push(String(ch)));
    stream.on('end', done);
    stream.on('error', done);
  });
  await c.stop().catch(() => undefined);
  const xml = chunks.join('');
  const failed = [...xml.matchAll(/<rule [^>]*status="failed"[\s\S]*?<\/rule>/g)]
    .map((m) => m[0].replace(/<check [\s\S]*?<\/check>/g, '').slice(0, 600))
    .join('\n');
  return { compliant: /isCompliant="true"/.test(xml), failed: failed || xml.slice(-4000) };
}
```

```ts
import { pdfStaticText, pdfTextIssues, type PdfOptions } from '@carbone-reports/shared';
import { unsupportedChars } from '../pdf/font';
import type { ChartIssue } from './charts';

export const pdfaMessage = (name: string) => `PDF/A включён: файл «${name}» не в формате PDF/A`;

function textIssue(path: string, text: string, tags: 'allowed' | 'none'): ChartIssue | null {
  if (tags === 'none') {
    if (text.includes('{d.')) return { path, message: 'в нумерации теги {d.…} не поддерживаются' };
  } else {
    const tagIssue = pdfTextIssues(text);
    if (tagIssue) return { path, message: tagIssue };
  }
  const bad = unsupportedChars(tags === 'none' ? text : pdfStaticText(text));
  if (bad.length) return { path, message: `символ «${bad[0]}» не поддерживается шрифтом PDF` };
  return null;
}

/** Проверки `PUT …/pdf-options` сверх схемы (§36.1, §36.2): теги и символы шрифта — у полей. */
export function pdfOptionIssues(o: PdfOptions): ChartIssue[] {
  const issues = [
    o.watermark && textIssue('/watermark/text', o.watermark.text, 'allowed'),
    o.pageNumbers && textIssue('/pageNumbers/format', o.pageNumbers.format, 'none'),
    ...(['title', 'author', 'subject', 'keywords'] as const).map(
      (k) => o.metadata && textIssue(`/metadata/${k}`, o.metadata[k], 'allowed'),
    ),
  ];
  return issues.filter((i): i is ChartIssue => Boolean(i));
}
```

```ts
    const next = { start: 0, end: 0 };
    for (const r of rows) {
      await tx
        .update(templateAttachments)

    let file: { filename: string; data: Buffer } | undefined;
    const fields: Record<string, string> = {};
    for await (const part of req.parts({ limits: { fileSize: MAX_PDF_ATTACHMENT_BYTES } })) {
      if (part.type === 'file') {

        file = { filename: part.filename, data: await part.toBuffer() };

    if (!file) throw badRequest('файл не передан');
    const placement = PdfPlacement.safeParse(fields.placement ?? 'end');
    if (!placement.success) throw badRequest('placement: start или end');
    const name = basename(file.filename || 'file.pdf').slice(0, 200) || 'file.pdf';
    return { name, data: file.data, placement: placement.data };

        .select({ id: templateAttachments.id })
        .from(templateAttachments)
        .where(eq(templateAttachments.filePath, path));

      let info: { pages: number; pdfa: boolean };
      try {

        throw e;
      }
      const path = templateAttachmentPath(row.id, randomUUID());
      await storage.write(path, data);
      try {
        await db.transaction(async (tx) => {
          await lockTemplate(tx, row.id);
          const cur = await loadTemplateAttachments(tx, row.id);
          if (cur.length >= MAX_PDF_ATTACHMENTS)
            throw badRequest(`в шаблоне не больше ${MAX_PDF_ATTACHMENTS} приложенных файлов`);
          if (cur.reduce((s, a) => s + a.pages, 0) + info.pages > MAX_PDF_ATTACHMENT_PAGES)
            throw badRequest(
              `в приложенных файлах шаблона не больше ${MAX_PDF_ATTACHMENT_PAGES} страниц`,

            .select({ pdfOptions: templates.pdfOptions })
            .from(templates)
            .where(eq(templates.id, row.id));

          await tx.insert(templateAttachments).values({

            placement,
            sortOrder: cur.filter((a) => a.placement === placement).length,
            name,
            filePath: path,
            size: data.length,
            pages: info.pages,
            pdfa: info.pdfa,
          });
          await touch(tx, row.id, currentUser(req).id);
        });
      } catch (err) {
        await discardAttachmentFile(path, req);
        throw err;
      }
      return reply.status(201).send(toAdminDetails(await loadTemplateFull(db, row.id)));
    },
  );

  app.patch(
    '/api/templates/:id/attachments/:aid',
    { ...admin, schema: { params: AttachmentParams, body: MoveAttachmentBody } },
    async (req) => {
      const row = await loadTemplate(db, req.params.id);
      await db.transaction(async (tx) => {
        await lockTemplate(tx, row.id);
        const rows = await loadTemplateAttachments(tx, row.id);
        const cur = rows.find((r) => r.id === req.params.aid);
        if (!cur) throw notFound('приложенный файл');
        const target = req.body.placement ?? cur.placement;
        const rest = rows.filter((r) => r.id !== cur.id);
        const group = rest.filter((r) => r.placement === target);
        const at = Math.min(req.body.sortOrder ?? group.length, group.length);
        group.splice(at, 0, { ...cur, placement: target });

        await renumber(tx, target === 'start' ? [...group, ...other] : [...other, ...group]);
        await touch(tx, row.id, currentUser(req).id);
      });
      return toAdminDetails(await loadTemplateFull(db, row.id));
    },
  );

  app.delete(
    '/api/templates/:id/attachments/:aid',
    { ...admin, schema: { params: AttachmentParams } },
    async (req) => {
      const row = await loadTemplate(db, req.params.id);
      const removed = await db.transaction(async (tx) => {

        const [del] = await tx
          .delete(templateAttachments)
          .where(
            and(
              eq(templateAttachments.id, req.params.aid),
              eq(templateAttachments.templateId, row.id),
            ),
          )
          .returning();
        if (!del) throw notFound('приложенный файл');

        .catch((e) => req.log.warn({ err: e }, 'приложенный файл не удалён'));
      return toAdminDetails(await loadTemplateFull(db, row.id));
    },
  );
}
```

```ts
import { fillPdfText, MAX_PDF_RESULT_BYTES, type PdfOptions } from '@carbone-reports/shared';
import type { TemplateAttachmentRow } from '../../db/schema';
import type { AppDeps } from '../../deps';
import { AppError, badRequest } from '../../lib/errors';
import type { TemplateFull } from '../templates/service';
import { sanitizePdfText } from './font';
import type { PdfPostJob } from './postprocess';

/** Настройки PDF шаблона для сборки отчёта (§36.4). */
export interface TemplatePdf {
  options: PdfOptions;
  /** В порядке итогового документа (loadTemplateAttachments). */
  attachments: Pick<
    TemplateAttachmentRow,
    'name' | 'placement' | 'sortOrder' | 'filePath' | 'pages' | 'pdfa'
  >[];
  templateName: string;
}

export const templatePdf = (full: TemplateFull): TemplatePdf => ({
  options: full.pdfOptions,
  attachments: full.attachments,
  templateName: full.row.name,
});

/** Без водяного знака, нумерации, метаданных и приложений PDF не обрабатывается (только PDF/A — тоже). */
export function needsPostprocess(p: TemplatePdf): boolean {
  const o = p.options;
  return Boolean(o.watermark || o.pageNumbers || o.metadata || p.attachments.length);
}

/** Тексты — с подставленными тегами и очищенные (R2); пустой водяной знак не ставится. */
export function buildPdfJob(
  p: TemplatePdf,
  data: unknown,
  now: Date,
  files: Uint8Array[],
): PdfPostJob {
  const o = p.options;
  const fill = (s: string) => sanitizePdfText(fillPdfText(s, data)).trim();
  const wmText = o.watermark ? fill(o.watermark.text) : '';
  return {
    pdfa: o.pdfa,
    watermark: o.watermark && wmText ? { ...o.watermark, text: wmText } : null,
    pageNumbers: o.pageNumbers ?? null,
    metadata: o.metadata
      ? {
          title: fill(o.metadata.title) || p.templateName,
          author: fill(o.metadata.author),
          subject: fill(o.metadata.subject),
          keywords: fill(o.metadata.keywords),
        }
      : null,
    attachments: p.attachments.map((a, i) => ({ placement: a.placement, data: files[i]! })),
    now: now.toISOString(),
  };
}

/** Итоговый PDF: приложения из хранилища, обработка в пуле, лимит 100 МБ (§36.4). */
export async function finishPdf(
  deps: Pick<AppDeps, 'storage' | 'pdf'>,
  pdf: Buffer,
  p: TemplatePdf,
  data: unknown,
  timeoutMs: number,
): Promise<Buffer> {
  if (!needsPostprocess(p)) return pdf;
  const files = await Promise.all(
    p.attachments.map(async (a) => {
      try {
        return await deps.storage.read(a.filePath);
      } catch (e) {
        throw new AppError('STORAGE_ERROR', 502, `приложенный файл «${a.name}» недоступен`, undefined, e);
      }
    }),
  );
  const out = await deps.pdf(pdf, buildPdfJob(p, data, new Date(), files), timeoutMs);
  if (out.length > MAX_PDF_RESULT_BYTES) throw badRequest('итоговый PDF больше 100 МБ');
  return out;
}
```

```ts
export function renderReport(
  deps: AppDeps,
  tpl: TemplateFileRef,
  data: unknown,
  format: OutputFormat,
  deadline?: Deadline,
  pdf?: TemplatePdf,
): Promise<Buffer> {
  // Срок уже истёк — не нагружать Carbone заведомо прерванной задачей.

      convertTo: format,
      lang: CARBONE_LANG,
      timezone: deps.config.tz,
      timeoutMs: timeoutMs(),

    });
    if (format !== 'pdf' || !pdf) return out;

  })();
  return deadline ? deadline.race(work) : work;
```

```tsx
  { key: 'subject', label: 'Тема' },
  { key: 'keywords', label: 'Ключевые слова' },

interface Draft {
  pdfa: boolean;
  wmOn: boolean;
  wm: PdfWatermark;
  pnOn: boolean;
  pn: PdfPageNumbers;
  meta: PdfMetadata;
}

function toDraft(o: PdfOptions): Draft {
  return {
    pdfa: o.pdfa,
    wmOn: Boolean(o.watermark),
    wm: o.watermark ?? { text: '', opacity: 20, color: 'gray', angle: 'diagonal' },
    pnOn: Boolean(o.pageNumbers),
    pn: o.pageNumbers ?? { format: PDF_PAGE_FORMAT_DEFAULT, position: 'bottom-center', skipFirst: false },
    meta: o.metadata ?? { title: '', author: '', subject: '', keywords: '' },
  };
}

function fromDraft(d: Draft): PdfOptions {
  return normalizePdfOptions({
    pdfa: d.pdfa,
    ...(d.wmOn ? { watermark: d.wm } : {}),
    ...(d.pnOn ? { pageNumbers: d.pn } : {}),
    metadata: d.meta,
  });
}

const kb = (n: number) => `${Math.max(1, Math.round(n / 1024))} КБ`;

  const { add } = useToaster();
  const fileRef = useRef<HTMLInputElement>(null);
  const [baseline, setBaseline] = useState(template.pdfOptions);

  const [placement, setPlacement] = useState<'start' | 'end'>('end');
  const [removing, setRemoving] = useState<TemplateAttachment | null>(null);
  const dirty = JSON.stringify(fromDraft(draft)) !== canon(baseline);
  // Настройки изменились на сервере: без несохранённых правок подхватываем, иначе — предупреждение.
  const stale = canon(template.pdfOptions) !== canon(baseline);

    setBaseline(t.pdfOptions);
    setDraft(toDraft(t.pdfOptions));
```

```markdown
## Настройки PDF

Вкладка «PDF» редактора шаблона задаёт, каким получится PDF отчёта — в предпросмотре, при формировании и скачивании:

- **PDF/A-2b** — для архива и электронного документооборота; PDF/A делает OnlyOffice Document Server.
- **Водяной знак** — текст по диагонали или горизонтально, прозрачность 10–50 %, серый, красный или синий.
- **Нумерация страниц** — «Стр. {page} из {pages}» или свой формат, внизу или вверху, можно не нумеровать первую страницу. Нумерация сквозная вместе с приложенными файлами.
- **Метаданные** — название (по умолчанию — имя шаблона), автор, тема, ключевые слова.
- **Приложенные файлы** — постоянные PDF шаблона (титульный лист, условия, приложения) в начале или в конце отчёта: до 10 файлов по 20 МБ, всего до 500 страниц, без пароля; при PDF/A — только файлы PDF/A.

В водяном знаке и метаданных можно писать теги `{d.поле}` без форматтеров: `Счёт № {d.number}`, `{d.status}` (пустое значение убирает водяной знак). «Сохранить как DOCX/XLSX…» отдаёт файл без настроек PDF. PDF уже сформированных отчётов при изменении настроек не меняется. Настройки и файлы переносятся вместе с шаблоном (экспорт и импорт) и копируются при «Дублировать».
```
