# 2.7.1: PDF — пароль и ограничения — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PDF сформированного отчёта защищается по настройкам шаблона: постоянный пароль на открытие и запреты печати, копирования и изменения (AES-256, программой `qpdf`); настройки — на вкладке «PDF», пароль хранится зашифрованным и не переносится между средами.

**Architecture:** Шифрование — `apps/api/src/modules/pdf/protect.ts`: `qpdf` запускается через `execFile` с файлом аргументов `@args` во временном каталоге (пароли не попадают в командную строку), не больше `renderWorkers` одновременно; подключается как `AppDeps.pdfProtect`. `finishPdf` (§36.4) после обработки `pdf-lib` вызывает `pdfProtect`, если у шаблона включена защита; защита (`TemplatePdf.protection`) собирается `templatePdf(full, key)` из `pdf_options.protection` и колонки `templates.pdf_password_enc` (миграция 0009, `encryptSecret`). Предпросмотр администратора строит `templatePdf(full, null)` — без защиты.

**Tech Stack:** Node 22, TypeScript, zod 4, vitest; Fastify 5 + drizzle-orm/drizzle-kit (Postgres); `qpdf` 11.3 (Debian bookworm, Apache-2.0) в образе API и на runner CI; `unpdf` (уже есть, devDependency) — проверка открытия с паролем в тестах; React 19 + Gravity UI.

**Spec:** `docs/superpowers/specs/2026-10-02-carbone-reports-design.md`, §37 (и §36 — PDF 2.7.0, §36.4 — `finishPdf` и снимок запуска, §36.6 — перенос, §33 — перенос шаблонов).

## Решения контроллера (там, где спецификация молчит)

- R1. `protection` без единого `true` не хранится (`normalizePdfOptions`), как пустые `metadata` в 2.7.0.
- R2. Тело `PUT …/pdf-options` — `SavePdfOptionsBody` = поля `PdfOptions` + `password?: string | null` (строгий объект). Ошибки схемы пароля приходят у поля `/password`.
- R3. Правило PDF/A проверяется по итоговому состоянию: `passwordSet` = (`password` не передан → сохранённый пароль есть; строка → да; `null` → нет). Ошибка — у поля `/pdfa`.
- R4. Срок `qpdf` — тот же `timeoutMs`, что получил `finishPdf` (как у обработки `pdf-lib`); при истечении — `SIGKILL` и 504. Общий `deadline.race` в `renderReport` остаётся.
- R5. Тестовое приложение (`createTestApp`) по умолчанию получает `pdfProtect`, который бросает «pdfProtect не настроен в тесте»; тесты рендера с защитой передают поддельный или настоящий защитник.
- R6. В архив переноса `pdfPasswordSet: true` пишется только у шаблона с паролем (без пароля — ключа нет): архивы шаблонов без пароля не меняются. Нарушение правила PDF/A в архиве — ошибка разбора манифеста (как правило PDF/A для приложений, §36.6).
- R7. «Дублировать» копирует `pdf_password_enc` как есть (та же среда, тот же ключ).
- R8. Проверка `qpdf --version` при старте — только предупреждение в лог; API стартует и без `qpdf`.

```ts
// ---- Пароль и ограничения (§37) ----

export const PDF_PASSWORD_MIN = 4;
export const PDF_PASSWORD_MAX = 64;
export const PDF_PROTECTION_PDFA_MESSAGE = 'PDF/A несовместим с паролем и ограничениями';

/** Запреты для программ просмотра; `true` — действие запрещено. */
export const PdfProtection = z.strictObject({
  noPrint: z.boolean().default(false),
  noCopy: z.boolean().default(false),
  noModify: z.boolean().default(false),
});
export type PdfProtection = z.infer<typeof PdfProtection>;

const isControl = (c: string) => {
  const n = c.codePointAt(0)!;
  return n < 0x20 || (n >= 0x7f && n <= 0x9f);
};

/** Пароль на открытие: длина — в символах, пробелы по краям — часть пароля. */
export const PdfPassword = z
  .string()
  .refine((s) => {
    const n = [...s].length;
    return n >= PDF_PASSWORD_MIN && n <= PDF_PASSWORD_MAX;
  }, `пароль — от ${PDF_PASSWORD_MIN} до ${PDF_PASSWORD_MAX} символов`)
  .refine((s) => ![...s].some(isControl), 'пароль содержит недопустимые символы');
```

```ts
/** Метаданные без единого значения и запреты без единого `true` не хранятся (R1). */
export function normalizePdfOptions(o: PdfOptions): PdfOptions {
  const { metadata, protection, ...rest } = o;
  return {
    ...rest,
    ...(metadata && Object.values(metadata).some((v) => v !== '') ? { metadata } : {}),
    ...(protection && Object.values(protection).some(Boolean) ? { protection } : {}),
  };
}

/** Защита включена: задан пароль на открытие или отмечен хотя бы один запрет (§37.1). */
export function hasPdfProtection(o: Pick<PdfOptions, 'protection'>, passwordSet: boolean): boolean {
  return passwordSet || Boolean(o.protection && Object.values(o.protection).some(Boolean));
}

/**
 * Тело `PUT …/pdf-options`: настройки и пароль. `password` не передан — пароль не меняется,
 * строка — новый пароль, `null` — пароль снимается.
 */
export const SavePdfOptionsBody = z.strictObject({
  ...PdfOptions.shape,
  password: PdfPassword.nullable().optional(),
});
export type SavePdfOptionsBody = z.infer<typeof SavePdfOptionsBody>;
```

```ts
import { execFile } from 'node:child_process';
import { randomBytes } from 'node:crypto';
import { mkdtemp, readFile, rm, writeFile } from 'node:fs/promises';
import { tmpdir } from 'node:os';
import { join } from 'node:path';
import type { PdfProtector } from '../../deps';
import { AppError } from '../../lib/errors';

/** Защита итогового PDF (§37.2). `userPassword: ''` — документ открывается без пароля. */
export interface PdfProtectJob {
  userPassword: string;
  noPrint: boolean;
  noCopy: boolean;
  noModify: boolean;
}

const unavailable = () =>
  new AppError('PDF_PROTECT_UNAVAILABLE', 503, 'шифрование PDF недоступно: не установлен qpdf');
const timeout = () => new AppError('TIMEOUT', 504, 'превышено время ожидания');

/** Аргументы qpdf 11.3 (позиционный `--encrypt`, AES-256); пишутся по одному на строку в файл @args. */
export function qpdfArgs(
  job: PdfProtectJob,
  owner: string,
  input: string,
  output: string,
): string[] {
  return [
    input,
    '--encrypt',
    job.userPassword,
    owner,
    '256',
    ...(job.noPrint ? ['--print=none'] : []),
    ...(job.noCopy ? ['--extract=n'] : []),
    ...(job.noModify ? ['--modify=none'] : []),
    '--',
    output,
  ];
}

/** Не больше `max` задач одновременно; освободившееся место передаётся следующему в очереди. */
export function limiter(max: number) {
  let active = 0;
  const queue: (() => void)[] = [];
  return async <T>(fn: () => Promise<T>): Promise<T> => {
    if (active < max) active++;
    else await new Promise<void>((resolve) => queue.push(resolve));
    try {
      return await fn();
    } finally {
      const next = queue.shift();
      if (next) next();
      else active--;
    }
  };
}

function runQpdf(bin: string, argsFile: string, timeoutMs: number): Promise<void> {
  if (timeoutMs <= 0) return Promise.reject(timeout());
  return new Promise((resolve, reject) => {
    execFile(
      bin,
      [`@${argsFile}`],
      { timeout: timeoutMs, killSignal: 'SIGKILL', maxBuffer: 1024 * 1024 },
      (err, _stdout, stderr) => {
        if (!err) return resolve();
        const e = err as NodeJS.ErrnoException & { code?: string | number; killed?: boolean };
        if (e.code === 'ENOENT') return reject(unavailable());
        if (e.killed) return reject(timeout());
        // 3 — готово с предупреждениями: файл записан.
        if (e.code === 3) return resolve();
        // В stderr qpdf — пути и описание ошибки, без аргументов из файла @args.
        const cause = new Error(`qpdf: код ${String(e.code)}: ${String(stderr).slice(0, 2000)}`);
        reject(new AppError('PDF_ERROR', 502, 'не удалось зашифровать PDF', undefined, cause));
      },
    );
  });
}

/**
 * Шифрование готового PDF программой qpdf (§37.2). Пароли — только в файле аргументов во временном
 * каталоге (0700, файлы 0600); каталог удаляется при любом исходе. Пароль владельца — случайный.
 */
export function createQpdfProtector(opts: {
  bin?: string;
  maxConcurrent: number;
  tmpRoot?: string;
}): PdfProtector {
  const bin = opts.bin ?? 'qpdf';
  const limit = limiter(opts.maxConcurrent);
  return (pdf, job, timeoutMs) =>
    limit(async () => {
      const started = Date.now();
      const dir = await mkdtemp(join(opts.tmpRoot ?? tmpdir(), 'cr-qpdf-'));
      try {
        const input = join(dir, 'in.pdf');
        const output = join(dir, 'out.pdf');
        const argsFile = join(dir, 'args');
        await writeFile(input, pdf, { mode: 0o600 });
        const owner = randomBytes(32).toString('base64url');
        await writeFile(argsFile, `${qpdfArgs(job, owner, input, output).join('\n')}\n`, {
          mode: 0o600,
        });
        await runQpdf(bin, argsFile, timeoutMs - (Date.now() - started));
        return await readFile(output);
      } finally {
        await rm(dir, { recursive: true, force: true });
      }
    });
}

/** Версия qpdf или null, если программы нет: проверка при старте API (R8). */
export function qpdfVersion(bin = 'qpdf'): Promise<string | null> {
  return new Promise((resolve) => {
    execFile(bin, ['--version'], { timeout: 5000 }, (err, stdout) =>
      resolve(err ? null : (String(stdout).split('\n')[0] ?? '').trim()),
    );
  });
}
```

```markdown
## [2.7.1] — 2026-10-15

### Добавлено

- Блок «Защита» на вкладке «PDF»: пароль на открытие и запреты печати, копирования текста и изменения (AES-256). Пароль хранится зашифрованным и в интерфейсе не показывается.
- Запреты переносятся между средами и копируются при «Дублировать» вместе с паролем; при импорте в другую среду пароль не переносится — окно загрузки предупреждает об этом.

### Изменено

- Образ API: добавлен `qpdf` (Debian bookworm), <старый размер> → <новый размер> МБ. Без `qpdf` API запускается, но отчёты с паролем или запретами получают ошибку 503 — при сборке своего образа установите пакет `qpdf`.
- При обновлении применяется миграция `0009_pdf_password` (колонка пароля PDF; существующие данные не меняются).

### Ограничения

- PDF/A и защита несовместимы.
- Защита действует на PDF сформированных отчётов; предпросмотр администратора и «Сохранить как DOCX/XLSX…» — без неё. PDF уже сформированных отчётов при смене пароля не меняется.
- Электронная подпись — в 2.7.2.
```
