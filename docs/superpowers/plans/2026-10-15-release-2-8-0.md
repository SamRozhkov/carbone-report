# Выпуск 2.8.0 — редактор шаблона: один редактор, развёрнутый режим, перетаскивание тегов

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Шаблон одновременно редактирует один администратор (блокировка в Postgres с продлением и перехватом), остальные видят его в просмотре; вкладка «Документ» разворачивается во весь экран; теги и готовые «Конструкции» перетаскиваются из панели в документ.

**Architecture:** Новая таблица `template_edit_locks` и модуль API `edit-lock` (захват/продление одним условным `insert … on conflict … where`, перехват, освобождение); конфиг редактора, сохранение, замена файла, удаление и импорт проверяют блокировку. В вебе — хук `useEditLock` (продление раз в 20 с, освобождение при уходе), режимы правки и просмотра OnlyOffice, развёрнутый режим классом на контейнере (без переноса `iframe`), панель тегов с поиском, сворачиванием, перетаскиванием (`text/plain`) и «Конструкциями», сверенными со справкой.

**Tech Stack:** Fastify 5, drizzle-orm (Postgres), zod 4, vitest + testcontainers; React 19, Gravity UI, TanStack Query, `@onlyoffice/document-editor-react`; Playwright (e2e на локальном стеке).

**Spec:** `docs/superpowers/specs/2026-10-02-carbone-reports-design.md` §38 (и §22 — OnlyOffice, §33 — перенос шаблонов, §26.3 — обслуживание).

## Global Constraints

- Миграция — `0010`, генерируется `drizzle-kit generate --name template_edit_locks`.

## Review Focus

1. Два администратора одновременно открывают свободный шаблон — ровно один получает правку, второй видит «Только просмотр» (гонка захвата; тест в Task 2).
2. Вкладка редактора закрыта аварийно (без `DELETE`) — через 60 с другой администратор получает правку без перехвата (тест на просроченную блокировку в Task 2; сдвиг `heartbeat_at` в прошлое).
3. Перехват, когда Document Server недоступен или отвечает «изменений нет» — перехват всё равно `200 mine` (Task 2).
4. Переключение вкладок шаблона (Данные, Графики…) не снимает блокировку и не пересоздаёт редактор; уход со страницы шаблона — снимает (Task 4).
5. Разворачивание и сворачивание не пересоздают редактор OnlyOffice (тот же экземпляр — счётчик монтирований, Task 5).

```ts
// packages/shared/src/edit-lock.ts
import { z } from 'zod';

/** Блокировка редактирования шаблона (§38.1): действует 60 с с последнего продления. */
export const EDIT_LOCK_TTL_SECONDS = 60;
/** Браузер продлевает блокировку раз в 20 с (§38.3). */
export const EDIT_LOCK_HEARTBEAT_MS = 20_000;

/** Номер вкладки «Документ» — случайный UUID, новый на каждое открытие вкладки. */
export const EditLockHolder = z.uuid();

export const EditLockBody = z.object({ holder: EditLockHolder, acquire: z.boolean() });
export type EditLockBody = z.infer<typeof EditLockBody>;

export const EditLockTakeoverBody = z.object({ holder: EditLockHolder });
export type EditLockTakeoverBody = z.infer<typeof EditLockTakeoverBody>;

export const EditLockHolderQuery = z.object({ holder: EditLockHolder });

export const EditLockState = z.discriminatedUnion('state', [
  z.object({ state: z.literal('mine') }),
  z.object({
    state: z.literal('other'),
    user: z.object({ id: z.string(), login: z.string() }),
    /** Начало блокировки, ISO-8601. */
    since: z.string(),
    /** Блокировка у другой вкладки той же учётной записи. */
    sameUser: z.boolean(),
  }),
  z.object({ state: z.literal('free') }),
]);
export type EditLockState = z.infer<typeof EditLockState>;

export const TemplateEditingBy = z.object({ login: z.string() });
export type TemplateEditingBy = z.infer<typeof TemplateEditingBy>;
```

```ts
/** Блокировка редактирования шаблона (§38.1): одна строка на шаблон; просроченная равна отсутствующей. */
export const templateEditLocks = pgTable('template_edit_locks', {
  templateId: uuid('template_id')
    .primaryKey()
    .references(() => templates.id, { onDelete: 'cascade' }),
  userId: uuid('user_id')
    .notNull()
    .references(() => users.id, { onDelete: 'cascade' }),
  /** Номер вкладки «Документ» (UUID из браузера). */
  holder: text('holder').notNull(),
  acquiredAt: timestamp('acquired_at', { withTimezone: true }).notNull(),
  heartbeatAt: timestamp('heartbeat_at', { withTimezone: true }).notNull(),
});
```

```ts
// apps/api/test/edit-lock.int.test.ts
import { randomUUID } from 'node:crypto';
import { eq, sql } from 'drizzle-orm';
import { afterAll, beforeAll, beforeEach, describe, expect, it } from 'vitest';
import { templateEditLocks, users } from '../src/db/schema';
import { createSourceDatabase, createTemplate, createTestApp, loginAs, type TestApp } from './helpers';

let t: TestApp;
let a: { cookie: string; id: string; login: string };
let b: { cookie: string; id: string; login: string };
let user: string;
let dsId: string;
let tplId: string;
const forceSaved: string[] = [];
let forceSaveError: Error | null = null;

async function admin() {
  const r = await loginAs(t, 'admin');
  return { cookie: r.cookie, id: r.user.id, login: r.user.login };
}
const lock = (cookie: string, holder: string, acquire = true, id = tplId) =>
  t.app.inject({
    method: 'POST',
    url: `/api/templates/${id}/edit-lock`,
    headers: { cookie },
    payload: { holder, acquire },
  });
const takeover = (cookie: string, holder: string) =>
  t.app.inject({
    method: 'POST',
    url: `/api/templates/${tplId}/edit-lock/takeover`,
    headers: { cookie },
    payload: { holder },
  });
const release = (cookie: string, holder: string) =>
  t.app.inject({
    method: 'DELETE',
    url: `/api/templates/${tplId}/edit-lock?holder=${holder}`,
    headers: { cookie },
  });
/** Сдвигает продление в прошлое — блокировка просрочена. */
const expire = () =>
  t.deps.db
    .update(templateEditLocks)
    .set({ heartbeatAt: sql`now() - interval '61 seconds'` })
    .where(eq(templateEditLocks.templateId, tplId));

beforeAll(async () => {
  t = await createTestApp({
    onlyoffice: {
      forceSave: async (key) => {
        forceSaved.push(key);
        if (forceSaveError) throw forceSaveError;
      },
    },
  });
  a = await admin();
  b = await admin();
  user = (await loginAs(t, 'user')).cookie;
  const src = await createSourceDatabase('select 1');
  const ds = await t.app.inject({
    method: 'POST',
    url: '/api/datasources',
    headers: { cookie: a.cookie },
    payload: { name: `ds-${randomUUID().slice(0, 6)}`, ...src, sslMode: 'disable' },
  });
  dsId = ds.json().id;
});
afterAll(() => t.close());
beforeEach(async () => {
  tplId = await createTemplate(t, a.cookie, dsId);
  forceSaved.length = 0;
  forceSaveError = null;
});

describe('edit-lock', () => {
  it('захват свободного, продление своим holder, чужой видит other', async () => {
    const ha = randomUUID();
    expect((await lock(a.cookie, ha)).json()).toEqual({ state: 'mine' });
    expect((await lock(a.cookie, ha)).json()).toEqual({ state: 'mine' });
    const r = await lock(b.cookie, randomUUID());
    expect(r.statusCode).toBe(200);
    expect(r.json()).toMatchObject({
      state: 'other',
      user: { id: a.id, login: a.login },
      sameUser: false,
    });
    expect(Date.parse(r.json().since)).not.toBeNaN();
  });

  it('вторая вкладка того же администратора — sameUser', async () => {
    await lock(a.cookie, randomUUID());
    expect((await lock(a.cookie, randomUUID())).json()).toMatchObject({
      state: 'other',
      sameUser: true,
    });
  });

  it('acquire: false — только чтение: free, other; свою продлевает', async () => {
    const ha = randomUUID();
    expect((await lock(a.cookie, ha, false)).json()).toEqual({ state: 'free' });
    const [none] = await t.deps.db
      .select()
      .from(templateEditLocks)
      .where(eq(templateEditLocks.templateId, tplId));
    expect(none).toBeUndefined();
    await lock(a.cookie, ha);
    expect((await lock(b.cookie, randomUUID(), false)).json()).toMatchObject({ state: 'other' });
    expect((await lock(a.cookie, ha, false)).json()).toEqual({ state: 'mine' });
  });

  it('просроченная блокировка свободна: захват другим, acquired_at обновлён', async () => {
    const ha = randomUUID();
    await lock(a.cookie, ha);
    await expire();
    expect((await lock(b.cookie, randomUUID(), false)).json()).toEqual({ state: 'free' });
    const hb = randomUUID();
    expect((await lock(b.cookie, hb)).json()).toEqual({ state: 'mine' });
    expect((await lock(a.cookie, ha)).json()).toMatchObject({
      state: 'other',
      user: { id: b.id },
    });
  });

  it('продление своим holder не меняет acquired_at', async () => {
    const ha = randomUUID();
    await lock(a.cookie, ha);
    const [r1] = await t.deps.db.select().from(templateEditLocks).where(eq(templateEditLocks.templateId, tplId));
    await new Promise((r) => setTimeout(r, 20));
    await lock(a.cookie, ha);
    const [r2] = await t.deps.db.select().from(templateEditLocks).where(eq(templateEditLocks.templateId, tplId));
    expect(r2!.acquiredAt.getTime()).toBe(r1!.acquiredAt.getTime());
    expect(r2!.heartbeatAt.getTime()).toBeGreaterThanOrEqual(r1!.heartbeatAt.getTime());
  });

  it('гонка: из 10 одновременных захватов ровно один mine', async () => {
    const results = await Promise.all(
      Array.from({ length: 10 }, (_, i) => lock(i % 2 ? a.cookie : b.cookie, randomUUID())),
    );
    const states = results.map((r) => r.json().state);
    expect(states.filter((s) => s === 'mine')).toHaveLength(1);
    expect(states.filter((s) => s === 'other')).toHaveLength(9);
  });

  it('перехват: блокировка переходит, forcesave ключа документа, прежний видит other', async () => {
    const ha = randomUUID();
    await lock(a.cookie, ha);
    const hb = randomUUID();
    const r = await takeover(b.cookie, hb);
    expect(r.statusCode).toBe(200);
    expect(r.json()).toEqual({ state: 'mine' });
    expect(forceSaved).toHaveLength(1);
    expect((await lock(a.cookie, ha)).json()).toMatchObject({ state: 'other', user: { id: b.id } });
  });

  it('перехват свободного или своего — без forcesave', async () => {
    const hb = randomUUID();
    await takeover(b.cookie, hb);
    await takeover(b.cookie, hb);
    await lock(a.cookie, randomUUID()); // other — ничего не меняет
    await expire();
    await takeover(a.cookie, randomUUID());
    expect(forceSaved).toHaveLength(0);
  });

  it('ошибка forcesave (сервер недоступен, нет изменений) не мешает перехвату', async () => {
    await lock(a.cookie, randomUUID());
    forceSaveError = Object.assign(new Error('сервер документов недоступен'), { statusCode: 502 });
    const r = await takeover(b.cookie, randomUUID());
    expect(r.statusCode).toBe(200);
    expect(r.json()).toEqual({ state: 'mine' });
  });

  it('освобождение: только своим holder, всегда 204', async () => {
    const ha = randomUUID();
    await lock(a.cookie, ha);
    expect((await release(b.cookie, randomUUID())).statusCode).toBe(204);
    expect((await lock(b.cookie, randomUUID(), false)).json()).toMatchObject({ state: 'other' });
    expect((await release(a.cookie, ha)).statusCode).toBe(204);
    expect((await lock(b.cookie, randomUUID(), false)).json()).toEqual({ state: 'free' });
  });

  it('проверки: holder не UUID — 400, не администратор — 403, нет шаблона — 404', async () => {
    expect((await lock(a.cookie, 'not-uuid')).statusCode).toBe(400);
    expect((await lock(user, randomUUID())).statusCode).toBe(403);
    expect((await lock(a.cookie, randomUUID(), true, randomUUID())).statusCode).toBe(404);
    expect(
      (
        await t.app.inject({
          method: 'DELETE',
          url: `/api/templates/${tplId}/edit-lock?holder=x`,
          headers: { cookie: a.cookie },
        })
      ).statusCode,
    ).toBe(400);
  });

  it('удаление пользователя снимает его блокировку', async () => {
    const c = await admin();
    await lock(c.cookie, randomUUID());
    await t.deps.db.delete(users).where(eq(users.id, c.id));
```

```ts
// apps/api/src/modules/edit-lock/service.ts
import { EDIT_LOCK_TTL_SECONDS, type EditLockState } from '@carbone-reports/shared';
import { and, eq, sql, type SQL } from 'drizzle-orm';
import { templateEditLocks, templates, users } from '../../db/schema';
import type { AppDeps } from '../../deps';
import { AppError, notFound } from '../../lib/errors';

export type LockDb = Pick<AppDeps['db'], 'select' | 'insert' | 'update' | 'delete'>;

export interface ActiveLock {
  holder: string;
  userId: string;
  login: string;
  since: Date;
}

/** Блокировка действует 60 с с последнего продления — по часам базы (§38.1). */
export const lockAlive: SQL = sql`${templateEditLocks.heartbeatAt} > now() - make_interval(secs => ${EDIT_LOCK_TTL_SECONDS})`;

export const lockedError = (login: string) =>
  new AppError('TEMPLATE_LOCKED', 409, `шаблон редактирует ${login}`);

export async function activeLock(db: LockDb, templateId: string): Promise<ActiveLock | null> {
  const [r] = await db
    .select({
      holder: templateEditLocks.holder,
      userId: templateEditLocks.userId,
      login: users.login,
      since: templateEditLocks.acquiredAt,
    })
    .from(templateEditLocks)
    .innerJoin(users, eq(users.id, templateEditLocks.userId))
    .where(and(eq(templateEditLocks.templateId, templateId), lockAlive));
  return r ?? null;
}

export function lockState(lock: ActiveLock | null, holder: string, userId: string): EditLockState {
  if (!lock) return { state: 'free' };
  if (lock.holder === holder) return { state: 'mine' };
  return {
    state: 'other',
    user: { id: lock.userId, login: lock.login },
    since: lock.since.toISOString(),
    sameUser: lock.userId === userId,
  };
}

/**
 * Строка шаблона `for share`: шаблон существует (иначе 404), и захват не пересекается с заменой файла,
 * удалением и импортом, которые проверяют блокировку под `for update` (§38.2).
 */
async function shareTemplate(tx: LockDb, templateId: string): Promise<void> {
  const [row] = await tx
    .select({ id: templates.id })
    .from(templates)
    .where(eq(templates.id, templateId))
    .for('share');
  if (!row) throw notFound('шаблон');
}

/** Захват или продление (§38.1): одна строка — `insert … on conflict … where`. */
export async function acquireLock(
  db: AppDeps['db'],
  templateId: string,
  holder: string,
  userId: string,
): Promise<EditLockState> {
  return db.transaction(async (tx) => {
    await shareTemplate(tx, templateId);
    const got = await tx
      .insert(templateEditLocks)
      .values({ templateId, holder, userId, acquiredAt: sql`now()`, heartbeatAt: sql`now()` })
      .onConflictDoUpdate({
        target: templateEditLocks.templateId,
        set: {
          holder,
          userId,
          // Своё продление не сдвигает начало блокировки.
          acquiredAt: sql`case when ${templateEditLocks.holder} = ${holder} then ${templateEditLocks.acquiredAt} else now() end`,
          heartbeatAt: sql`now()`,
        },
        setWhere: sql`${templateEditLocks.holder} = ${holder} or not (${lockAlive})`,
      })
      .returning({ templateId: templateEditLocks.templateId });
    if (got.length > 0) return { state: 'mine' } as const;
    return lockState(await activeLock(tx, templateId), holder, userId);
  });
}

/** Только чтение (вкладка в просмотре); свою блокировку продлевает. */
export async function peekLock(
  db: AppDeps['db'],
  templateId: string,
  holder: string,
  userId: string,
): Promise<EditLockState> {
  return db.transaction(async (tx) => {
    await shareTemplate(tx, templateId);
    const renewed = await tx
      .update(templateEditLocks)
      .set({ heartbeatAt: sql`now()` })
      .where(
        and(
          eq(templateEditLocks.templateId, templateId),
          eq(templateEditLocks.holder, holder),
          lockAlive,
        ),
      )
      .returning({ templateId: templateEditLocks.templateId });
    if (renewed.length > 0) return { state: 'mine' } as const;
    return lockState(await activeLock(tx, templateId), holder, userId);
  });
}

/**
 * Перехват (§38.1): блокировка переходит безусловно. Возвращает прежнюю действовавшую блокировку
 * другой вкладки (для forcesave) или null.
 */
export async function takeOverLock(
  db: AppDeps['db'],
  templateId: string,
  holder: string,
  userId: string,
): Promise<{ previous: ActiveLock | null; docKey: string }> {
  return db.transaction(async (tx) => {
    const [row] = await tx
      .select({ id: templates.id, docKey: templates.docKey })
      .from(templates)
      .where(eq(templates.id, templateId))
      .for('share');
    if (!row) throw notFound('шаблон');
    const before = await activeLock(tx, templateId);
    await tx
      .insert(templateEditLocks)
      .values({ templateId, holder, userId, acquiredAt: sql`now()`, heartbeatAt: sql`now()` })
      .onConflictDoUpdate({
        target: templateEditLocks.templateId,
        set: { holder, userId, acquiredAt: sql`now()`, heartbeatAt: sql`now()` },
      });
    return { previous: before && before.holder !== holder ? before : null, docKey: row.docKey };
  });
}

export async function releaseLock(db: LockDb, templateId: string, holder: string): Promise<void> {
  await db
    .delete(templateEditLocks)
    .where(and(eq(templateEditLocks.templateId, templateId), eq(templateEditLocks.holder, holder)));
}

export async function assertNotLockedByOther(
  db: LockDb,
  templateId: string,
  holder: string | null,
): Promise<void> {
  const lock = await activeLock(db, templateId);
  if (lock && lock.holder !== holder) throw lockedError(lock.login);
}

export async function assertLockedBy(db: LockDb, templateId: string, holder: string): Promise<void> {
  const lock = await activeLock(db, templateId);
  if (!lock) throw new AppError('TEMPLATE_LOCKED', 409, 'начните редактирование');
  if (lock.holder !== holder) throw lockedError(lock.login);
}
```

Если `AppDeps['db']` не имеет `.transaction` в типе `LockDb` — так и задумано: транзакционные функции принимают `AppDeps['db']`, проверки — `LockDb` (их вызывают и внутри чужих транзакций).

```ts
export function registerEditLockRoutes(app: App, deps: AppDeps, guards: Guards): void {
  const admin = { preHandler: guards.requireAdmin };

  app.post(
    '/api/templates/:id/edit-lock',

        req.params.id,
        req.body.holder,

    '/api/templates/:id/edit-lock',
```

```ts
// apps/web/src/pages/admin/template-editor/useEditLock.ts
import { EDIT_LOCK_HEARTBEAT_MS, type EditLockState } from '@carbone-reports/shared';
import { useCallback, useEffect, useRef, useState } from 'react';
import { api, releaseEditLock } from '../../../api/endpoints';

export interface EditLock {
  holder: string;
  state: EditLockState | null;
  lostTo: string | null;
  offline: boolean;
  editing: boolean;
  start(): Promise<void>;
  takeover(): Promise<void>;
}

const FAILS_BEFORE_OFFLINE = 3;

/** Блокировка редактирования для вкладки «Документ» (§38.3). */
export function useEditLock(templateId: string): EditLock {
  const [holder] = useState(() => crypto.randomUUID());
  const [state, setState] = useState<EditLockState | null>(null);
  const [lostTo, setLostTo] = useState<string | null>(null);
  const [offline, setOffline] = useState(false);
  const stateRef = useRef<EditLockState | null>(null);
  const fails = useRef(0);
  const alive = useRef(true);

  const apply = useCallback((next: EditLockState) => {
    const prev = stateRef.current;
    if (prev?.state === 'mine' && next.state === 'other') setLostTo(next.user.login);
    if (next.state === 'mine') setLostTo(null);
    stateRef.current = next;
    setState(next);
  }, []);

  const call = useCallback(
    async (acquire: boolean) => {
      try {
        const next = await api.templates.editLock(templateId, { holder, acquire });
        fails.current = 0;
        if (!alive.current) return;
        setOffline(false);
        apply(next);
      } catch {
        fails.current += 1;
        if (alive.current && fails.current >= FAILS_BEFORE_OFFLINE) setOffline(true);
      }
    },
    [templateId, holder, apply],
  );

  useEffect(() => {
    alive.current = true;
    void call(true);
    const timer = setInterval(
      () => void call(stateRef.current?.state === 'mine'),
      EDIT_LOCK_HEARTBEAT_MS,
    );
    const onHide = () => releaseEditLock(templateId, holder);
    window.addEventListener('pagehide', onHide);
    return () => {
      alive.current = false;
      clearInterval(timer);
      window.removeEventListener('pagehide', onHide);
      releaseEditLock(templateId, holder);
    };
  }, [call, templateId, holder]);

  return {
    holder,
    state,
    lostTo,
    offline,
    editing: state?.state === 'mine',
    start: () => call(true),
    takeover: async () => {
      apply(await api.templates.takeoverEditLock(templateId, holder));
    },
  };
}
```

```tsx
export function filterTree(nodes: TagNode[], query: string): TagNode[] {
  const q = query.trim().toLowerCase();
  if (!q) return nodes;
  const hit = (n: TagNode) =>
    n.label.toLowerCase().includes(q) ||
    (n.tag ?? '').toLowerCase().includes(q) ||
    (n.nextRowTag ?? '').toLowerCase().includes(q);
  return nodes.flatMap((n) => {
    if (hit(n)) return [n];
    const children = filterTree(n.children, q);
    return children.length > 0 ? [{ ...n, children }] : [];
  });
}

export function TagTile({ text, hint, editing }: { text: string; hint?: string; editing: boolean }) {
  const copy = useCopy();
  return (
    <div style={{ display: 'flex', alignItems: 'center', gap: 6 }}>
      <span
        className="cr-tag-tile"
        draggable={editing}
        title={editing ? 'Перетащите в документ или скопируйте' : undefined}
        style={{ cursor: editing ? 'grab' : undefined }}
        onDragStart={(e) => {
          e.dataTransfer.setData('text/plain', text);
          e.dataTransfer.effectAllowed = 'copy';
        }}
      >
        <Text variant="code-1">{text}</Text>
      </span>
      {hint && (
        <Text variant="caption-2" color="secondary">
          {hint}
        </Text>
      )}
      <Button view="flat" size="xs" aria-label={`Скопировать ${text}`} title="Скопировать" onClick={() => void copy(text)}>
        <Icon data={Copy} size={12} />
      </Button>
    </div>
  );
}
```

```ts
// e2e/tests/editor-lock.spec.ts
import { randomUUID } from 'node:crypto';
import type { Page } from '@playwright/test';
import { adminApi, demoTemplateId, docxText, expect, loginAdminUi, loginUi, test, waitForStack, type ApiClient } from '../fixtures';

let api: ApiClient;
let templateId: string;
const second = { login: `e2e_admin_${randomUUID().slice(0, 6)}`, password: `P${randomUUID()}` };
let secondId: string;

test.beforeAll(async () => {
  await waitForStack();
  api = await adminApi();
  templateId = await demoTemplateId(api);
  // Тело создания пользователя — как в access.spec.ts / admin-data.spec.ts.
  secondId = (await api.post<{ id: string }>('/api/users', { login: second.login, password: second.password, role: 'admin' })).id;
});
test.afterAll(async () => {
  await api.ctx.delete(`/api/users/${secondId}`);
  await api.ctx.dispose();
});

async function openDocument(page: Page) {
  await page.goto(`/admin/templates/${templateId}?tab=document`);
  const frame = page.frameLocator('iframe[name="frameEditor"]');
  await expect(frame.locator('#id_viewer')).toBeVisible({ timeout: 180_000 });
  await expect(frame.locator('.asc-loadmask')).toHaveCount(0, { timeout: 120_000 });
  return frame;
}

test('два администратора: просмотр, перехват, правка переходит', async ({ page, browser }) => {
  await loginAdminUi(page);
  await openDocument(page);
  await expect(page.getByText('Вы редактируете')).toBeVisible();

  const ctx2 = await browser.newContext({ ignoreHTTPSErrors: true, locale: 'ru-RU', viewport: { width: 1440, height: 900 } });
  const p2 = await ctx2.newPage();
  await loginUi(p2, second.login, second.password);
  await openDocument(p2);
  await expect(p2.getByText(/Только просмотр — редактирует/)).toBeVisible();
  await expect(p2.getByRole('button', { name: 'Сохранить' })).toHaveCount(0);

  // Развёрнутый режим: диалог перехвата виден поверх и нажимается.
  await p2.getByRole('button', { name: 'Развернуть' }).click();
  await p2.getByRole('button', { name: 'Забрать редактирование' }).click();
  await p2.getByRole('button', { name: 'Забрать' }).click();
  await expect(p2.getByText('Вы редактируете')).toBeVisible({ timeout: 60_000 });

  await expect(page.getByText(new RegExp(`Редактирование забрал ${second.login}`))).toBeVisible({ timeout: 40_000 });
  await expect(page.getByRole('button', { name: 'Сохранить' })).toHaveCount(0);
  await ctx2.close();
});

test('перетаскивание тега из панели в документ, сборка подставляет значение', async ({ page }) => {
  await loginAdminUi(page);
  const frame = await openDocument(page);
  await expect(page.getByText('Вы редактируете')).toBeVisible({ timeout: 60_000 });
  await page.getByRole('button', { name: 'Обновить данные' }).click();
  const tile = page.locator('[draggable="true"]', { hasText: '{d.company.inn}' });
  await expect(tile).toBeVisible({ timeout: 60_000 });
  await frame.locator('#id_viewer_overlay').click({ position: { x: 300, y: 200 } });
  await page.keyboard.press('ControlOrMeta+End');
  await page.keyboard.press('Enter');
  const box = (await frame.locator('#id_viewer_overlay').boundingBox())!;
  const from = (await tile.boundingBox())!;
  await page.mouse.move(from.x + 5, from.y + 5);
  await page.mouse.down();
  await page.mouse.move(box.x + box.width / 2, box.y + box.height / 2, { steps: 15 });
  await page.mouse.move(box.x + box.width / 2 + 3, box.y + box.height / 2 + 3, { steps: 3 });
  await page.mouse.up();
  await expect(frame.getByText('Все изменения сохранены')).toBeVisible({ timeout: 60_000 });
  await page.getByRole('button', { name: 'Сохранить' }).click();
  await expect(page.getByText(/Сохранено, версия \d+/)).toBeVisible({ timeout: 90_000 });
  const { runId } = await api.post<{ runId: string }>(`/api/reports/${templateId}/render`, { params: { invoiceId: 1 } });
  const file = await api.ctx.get(`/api/runs/${runId}/file?format=docx`);
  expect(await docxText(Buffer.from(await file.body()))).toContain('7701234567');
});
```
