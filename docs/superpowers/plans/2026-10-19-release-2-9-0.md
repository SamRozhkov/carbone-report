# 2.9.0: электронная подпись PDF — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Пользователь загружает свой сертификат `.p12` на странице «Моя подпись» и подписывает сформированный PDF-отчёт (PAdES B-B, при настроенной службе меток — B-T) с видимым штампом на последней странице; шаблон разрешает подпись флажком на вкладке «PDF».

**Architecture:** Модуль `apps/api/src/modules/pdf/sign/`: `p12.ts` открывает `.p12` (`node-forge` — только контейнер; ключ — `KeyObject` Node, сертификаты — DER), `prepare.ts` (в пуле рендера, задача `kind: 'sign'`) добавляет `pdf-lib` поле подписи со штампом и местом под CMS, `cms.ts` собирает CMS `SignedData` структурами `pkijs`/`asn1js` и подписывает `crypto.sign` Node, `tsa.ts` получает метку RFC 3161, `sign-pdf.ts` связывает шаги через интерфейс `CmsSigner`. Ключ не покидает главный поток. Сертификат хранится в `user_certificates` (`encryptSecret`), подпись запуска — в `report_run_signatures` и `reports/<runId>/out.signed.pdf`.

**Tech Stack:** Node 22, TypeScript, zod 4, vitest; Fastify 5 + drizzle-orm/drizzle-kit (Postgres), `@fastify/rate-limit` 11.2 (Redis); `pdf-lib` 1.17.1, `@pdf-lib/fontkit` (уже есть); новые: `pkijs`, `asn1js`, `node-forge` (+ `@types/node-forge`, dev); OpenSSL 3 (тестовые сертификаты, `openssl cms -verify` в тестах); pyHanko и veraPDF — только CI; React 19 + Gravity UI + TanStack Query; Playwright (e2e).

**Spec:** `docs/superpowers/specs/2026-10-02-carbone-reports-design.md`, §39 (и §36 — PDF 2.7.0: `visualView`/`toPage`, шрифт, `finishPdf`; §37 — защита и правило PDF/A, образец правила совместимости; §24 — снимок запуска, `runFileGate`, файлы запуска; §21 — лимиты в Redis).

## Решения контроллера (там, где спецификация молчит)

- R1. Порядок задач: проверка риска (§39.7, «первая задача плана») — Task 5, сразу после ядра подписи (Tasks 2–4), которое она проверяет, и до любой работы над API и интерфейсом. Task 1 — только схемы `packages/shared` без потребителей.
- R2. Криптография: `node-forge` только разбирает контейнер PKCS#12 (MAC, расшифровка мешков); ключ — `crypto.createPrivateKey` (PKCS#8 DER), подпись — `crypto.sign` (RSA — PKCS#1 v1.5, ECDSA — DER); сертификаты разбираются `X509Certificate` Node (ключ ↔ сертификат: `checkPrivateKey`) и `pkijs` (CN, `keyUsage`). WebCrypto не используется.
- R3. Подготовка PDF (`pdf-lib`, тяжёлая) — задача пула рендера `kind: 'sign'`; хэш, CMS, метка времени и вставка — в главном потоке: ключ не передаётся в поток пула.
- R4. Интерфейс `CmsSigner` из спецификации дополнен полем `reserveBytes: number` — сколько байт CMS может занять (`сумма DER сертификатов + 12 288`); `/Contents` = `2 × reserveBytes` знаков.
- R5. Признак ГОСТ — в DER файла есть OID с префиксом `1.2.643` (байты `06 ?? 2A 85 03`); проверяется до разбора `node-forge` (у ГОСТ-контейнеров КриптоПро внешние алгоритмы тоже ГОСТ).
- R6. `GET /api/me/certificate` отвечает `{ certificate: CertificateInfo | null }` (а не голым `null`: пустое тело ответа неоднозначно для клиента).
- R7. `ReportRunPage` узнаёт, разрешена ли подпись, из `TemplateDetails.signatureAllowed` (новое поле; снимок только что созданного запуска совпадает с шаблоном). Решает сервер — по снимку (§39.2).
- R8. Лимит неверных паролей: `app.createRateLimit({ max: 5, timeWindow: '15 minutes', nameSpace: 'cr:rl-sign:', keyGenerator: id пользователя })`. Перед расшифровкой — проверка без счёта (`{ increment: false }`): исчерпан — 429; неверный пароль — счёт (`limit(req)`) и 400. Порядок проверок подписи: запуск (404/400) → сертификат (400) → лимит (429) → блокировка и «уже подписан» (409) → пароль (400) → подпись.
- R9. Одна подпись на запуск — `runFileGate(RUN_FILE_LOCK_CLASS, '<runId>:signed', …)`: внутри транзакции — `FOR SHARE` строки запуска (как `buildRunFile`), проверка строки `report_run_signatures` (есть — 409), подпись, запись файла, вставка строки. При ошибке после записи файла — файл удаляется.
- R10. Имя подписанного файла — `<шаблон> <дата>-signed.pdf`; `signed=1` с форматом, отличным от `pdf`, — `400 VALIDATION` «формат недоступен для этого отчёта» (как `formatUnavailable`).
- R11. Очистка по сроку хранения удаляет строки `report_run_signatures` в той же транзакции, что ставит `file_deleted` (как `report_run_files`).
- R12. Таймаут метки: `min(SIGN_TSA_TIMEOUT_MS, остаток срока)`; оборвался по сроку отчёта — 504 `TIMEOUT`, по своему таймауту или сетевой ошибке — 502 `TSA_UNAVAILABLE`.
- R13. Проверка подписи в интеграционных тестах — `pyhanko sign validate --no-revocation-check --trust <ca.pem>`: код выхода 0 и в выводе `INTACT:TRUSTED`; с меткой — ещё `TIMESTAMP_TOKEN<INTACT:TRUSTED>`. В CI pyHanko ставится `pipx install pyhanko-cli==<версия>` (последняя на момент Task 5, закрепить), переменная `REQUIRE_PYHANKO=1`; локально без `pyhanko` в `PATH` такие тесты пропускаются.
- R14. Тело запроса в лог не пишется (сериализатор `req` в `createFastify` — только метод и адрес); для защиты от будущих правок в настройки логгера добавляется `redact: { paths: ['password', '*.password', 'body.password'], censor: '***' }`. В тестах логгер выключен, поэтому тесты проверяют утечку по ответам, `details`, строкам БД и файлам хранилища.
- R16. Положение штампа на момент запуска записывается в колонку `report_runs.signature_position text` (миграция 0011; `null` — подпись в снимке не разрешена): список истории и маршрут подписи не читают `pdf-options.json` из хранилища. Значение — `pdf.options.signature?.position` того же `TemplatePdf`, из которого пишется `pdf-options.json`, поэтому решение «по снимку» (§39.2) не меняется.
- R15. Пункт меню «Моя подпись» — в основном меню после «История», для всех ролей; путь `/signature`.

```sh
  }
```

```ts
export function hasGostOid(der: Uint8Array): boolean {
  for (let i = 0; i + 4 < der.length; i++)
    if (der[i] === 0x06 && der[i + 2] === 0x2a && der[i + 3] === 0x85 && der[i + 4] === 0x03)
      return true;
  return false;

  try {
    const asn1 = forge.asn1.fromDer(forge.util.createBuffer(Buffer.from(file).toString('binary')));
    return forge.pkcs12.pkcs12FromAsn1(asn1, true, password);
  } catch {
    // Причина (MAC, ASN.1) пользователю не нужна и может повторять входные данные.
    throw new P12Error('password', BAD_FILE);
  }
}

function bags(p12: forge.pkcs12.Pkcs12Pfx, type: string): Bag[] {
  return (p12.getBags({ bagType: type })[type] ?? []) as Bag[];
}

function keyAlg(key: KeyObject): { name: string; digestAlg: DigestAlg } | null {
  const d = key.asymmetricKeyDetails ?? {};
  if (key.asymmetricKeyType === 'rsa' && (d.modulusLength ?? 0) >= 2048)
    return { name: `RSA-${d.modulusLength}`, digestAlg: 'SHA-256' };
  if (key.asymmetricKeyType === 'ec' && d.namedCurve === 'prime256v1')
    return { name: 'ECDSA P-256', digestAlg: 'SHA-256' };
  if (key.asymmetricKeyType === 'ec' && d.namedCurve === 'secp384r1')
    return { name: 'ECDSA P-384', digestAlg: 'SHA-384' };
  return null;
}

const OID_CN = '2.5.4.3';
const OID_KEY_USAGE = '2.5.29.15';

function commonName(n: pkijs.RelativeDistinguishedNames): string | undefined {
  const cn = n.typesAndValues.find((t) => t.type === OID_CN);
  return cn ? String(cn.value.valueBlock.value) : undefined;
}

/** `keyUsage` нет — подпись не запрещена; есть — нужен digitalSignature или nonRepudiation. */
function allowsSigning(c: pkijs.Certificate): boolean {
  const ext = c.extensions?.find((e) => e.extnID === OID_KEY_USAGE);
  if (!ext) return true;
  const bits = (ext.parsedValue as asn1js.BitString).valueBlock.valueHexView;
  return ((bits[0] ?? 0) & 0xc0) !== 0;
}

export function certInfo(der: Uint8Array, keyAlgName: string): CertificateInfo {
  const x = new X509Certificate(der);
  const c = pkijs.Certificate.fromBER(der);
  return {
    subjectCn: commonName(c.subject) ?? x.subject.split('\n').join(', '),
    issuer: commonName(c.issuer) ?? x.issuer.split('\n').join(', '),
    serial: x.serialNumber.toUpperCase(),
    notBefore: new Date(x.validFrom).toISOString(),
    notAfter: new Date(x.validTo).toISOString(),
    fingerprint: x.fingerprint256.replaceAll(':', '').toUpperCase(),
    keyAlg: keyAlgName,
  };
}

/** Открывает `.p12` паролем и проверяет пригодность для подписи (§39.1). */
export function readP12(file: Uint8Array, password: string, now = new Date()): P12Contents {
  if (file.length > MAX_P12_BYTES) throw new P12Error('file', 'файл больше 50 КБ');
  if (hasGostOid(file)) throw new P12Error('file', GOST);
  const p12 = openPfx(file, password);
  const oids = forge.pki.oids;
  const keyBags = [...bags(p12, oids.pkcs8ShroudedKeyBag!), ...bags(p12, oids.keyBag!)];
  const certs = bags(p12, oids.certBag!).map((b) =>
    toDer(b.cert ? forge.pki.certificateToAsn1(b.cert) : b.asn1!),
  );
  if (keyBags.length !== 1) throw new P12Error('file', ONE_KEY);
  const kb = keyBags[0]!;
  const pkcs8 = toDer(
    kb.key
      ? forge.pki.wrapRsaPrivateKey(forge.pki.privateKeyToAsn1(kb.key as forge.pki.rsa.PrivateKey))
      : kb.asn1!,
  );
  if (hasGostOid(pkcs8) || certs.some((c) => hasGostOid(c))) throw new P12Error('file', GOST);
  let key: KeyObject;
  try {
    key = createPrivateKey({ key: pkcs8, format: 'der', type: 'pkcs8' });
  } catch {
    throw new P12Error('file', UNSUPPORTED);
  }
  const idx = certs.findIndex((c) => {
    try {
      return new X509Certificate(c).checkPrivateKey(key);
    } catch {
      return false;
    }
  });
  if (idx < 0) throw new P12Error('file', ONE_KEY);
  const alg = keyAlg(key);
  if (!alg) throw new P12Error('file', UNSUPPORTED);
  const cert = certs[idx]!;
  const x = new X509Certificate(cert);
  if (now < new Date(x.validFrom)) throw new P12Error('file', 'сертификат ещё не действует');
  if (now > new Date(x.validTo)) throw new P12Error('file', 'срок действия сертификата истёк');
  if (!allowsSigning(pkijs.Certificate.fromBER(cert)))
    throw new P12Error('file', 'сертификат не предназначен для подписи');
  return {
    key,
    cert,
    chain: certs.filter((_, i) => i !== idx),
    info: certInfo(cert, alg.name),
    digestAlg: alg.digestAlg,
  };
}
```

```ts
// Место под подпись в готовом PDF (§39.4): ByteRange и /Contents. Работает с байтами, без pdf-lib.

/** Как заглушку ByteRange пишет pdf-lib: `[ 0 /********** /********** /********** ]`. */
const BYTE_RANGE = /\/ByteRange\s*\[\s*0\s+\/\*{10}\s+\/\*{10}\s+\/\*{10}\s*\]/g;

/** Границы значения /Contents: `start` — позиция «<», `end` — сразу после «>». */
export interface SignatureHole {
  start: number;
  end: number;
}

/** Находит заглушки, вписывает ByteRange той же ширины и возвращает место под CMS. */
export function fillByteRange(pdf: Buffer, contentsBytes: number): SignatureHole {
  const text = pdf.toString('latin1');
  const hole = `<${'0'.repeat(contentsBytes * 2)}>`;
  const start = text.indexOf(hole);
  if (start < 0 || text.indexOf(hole, start + 1) >= 0)
    throw new Error('место под подпись не найдено или не одно');
  const end = start + hole.length;
  const found = [...text.matchAll(BYTE_RANGE)];
  if (found.length !== 1) throw new Error('заглушка ByteRange не найдена или не одна');
  const m = found[0]!;
  const at = m.index + m[0].indexOf('[');
  const width = m.index + m[0].length - at;
  const value = `[0 ${start} ${end} ${pdf.length - end}]`;
  if (value.length > width) throw new Error('ByteRange не помещается в заглушку');
  pdf.write(value.padEnd(width, ' '), at, 'latin1');
  return { start, end };
}

/** Подписываемые байты: всё, кроме значения /Contents. */
export function signedRanges(pdf: Buffer, hole: SignatureHole): [Buffer, Buffer] {
  return [pdf.subarray(0, hole.start), pdf.subarray(hole.end)];
}

/** Вписывает DER подписи в /Contents (шестнадцатерично, дополняя нулями). */
export function insertCms(pdf: Buffer, hole: SignatureHole, cms: Uint8Array): void {
  const room = hole.end - hole.start - 2;
  const hex = Buffer.from(cms).toString('hex').toUpperCase();
  if (hex.length > room) throw new Error('CMS не помещается в /Contents');
  pdf.write(hex.padEnd(room, '0'), hole.start + 1, 'latin1');
}
```

```ts
    rectangle(0, 0, w, h),
    fill(),
    setStrokingRgbColor(...BLUE),
    setLineWidth(1),
    rectangle(0.5, 0.5, w - 1, h - 1),
    stroke(),
    setFillingRgbColor(...BLUE),
    beginText(),
  ];
  ops.push(
    setFontAndSize('F2', TITLE_SIZE),
    moveText(PAD, h - PAD - TITLE_SIZE),
    showText(bold.encodeText(stampText(lines[0], bold, TITLE_SIZE))),
    setFontAndSize('F1', LINE_SIZE),
  );
  for (const line of lines.slice(1)) {
    ops.push(moveText(0, -LINE_STEP), showText(regular.encodeText(stampText(line, regular, LINE_SIZE))));
  }
  ops.push(endText(), popGraphicsState());
  return ops;
}

/**
 * Поле подписи со штампом на последней странице и заглушки ByteRange и /Contents (§39.4).
 * Документ сохраняется целиком без изменения Info и XMP (PDF/A остаётся действительным).
 */
export async function prepareSignaturePdf(pdf: Uint8Array, job: SignPrepareJob): Promise<Uint8Array> {
  const doc = await PDFDocument.load(pdf, { updateMetadata: false });
  doc.registerFontkit(fontkit);
  const regular = await doc.embedFont(pdfFontBytes(), { subset: true });
  const bold = await doc.embedFont(pdfBoldFontBytes(), { subset: true });
  const page = doc.getPages().at(-1)!;
  const v = visualView(page);
  const { width: w, height: h, margin } = STAMP;
  const u =
    job.position === 'bottom-left' ? margin : job.position === 'bottom-center' ? (v.w - w) / 2 : v.w - margin - w;
  const a = toPage(v, u, margin);
  const b = toPage(v, u + w, margin + h);
  const rect = [Math.min(a.x, b.x), Math.min(a.y, b.y), Math.max(a.x, b.x), Math.max(a.y, b.y)];

  const appearance = doc.context.register(
    doc.context.formXObject(stampOperators(job.lines, regular, bold), {
      BBox: [0, 0, w, h],
      Matrix: MATRIX[v.rot],
      Resources: { Font: { F1: regular.ref, F2: bold.ref } },
    }),
  );
  const signature = doc.context.register(
    doc.context.obj({
      Type: 'Sig',
      Filter: 'Adobe.PPKLite',
      SubFilter: 'ETSI.CAdES.detached',
      ByteRange: [0, PLACEHOLDER, PLACEHOLDER, PLACEHOLDER],
      Contents: PDFHexString.of('0'.repeat(job.contentsBytes * 2)),
      M: PDFString.fromDate(new Date(job.signedAt)),
    }),
  );
  const widget = doc.context.register(
    doc.context.obj({
      Type: 'Annot',
      Subtype: 'Widget',
      FT: 'Sig',
      T: PDFString.of('Signature1'),
      Rect: rect,
      F: 4,
      P: page.ref,
      V: signature,
      AP: { N: appearance },
    }),
  );
  page.node.addAnnot(widget);
  const form = doc.catalog.getOrCreateAcroForm();
  form.addField(widget);
  form.dict.set(PDFName.of('SigFlags'), PDFNumber.of(3));
  return doc.save({ useObjectStreams: false, updateFieldAppearances: false });
}
```

```ts
// Только для тестов: подпись из PDF и проверка `openssl cms -verify` (тестовый УЦ — доверенный).
import { execFile } from 'node:child_process';
import { mkdtemp, rm, writeFile } from 'node:fs/promises';
import { tmpdir } from 'node:os';
import { join } from 'node:path';
import { promisify } from 'node:util';
import { fixturePath } from './fixtures';

const run = promisify(execFile);

/** CMS из /Contents и подписанные байты по /ByteRange (единственная подпись в файле). */
export function extractSignature(pdf: Buffer): { cms: Buffer; signed: Buffer } {
  const text = pdf.toString('latin1');
  const m = /\/ByteRange \[0 (\d+) (\d+) (\d+) *\]/.exec(text);
  if (!m) throw new Error('нет ByteRange');
  const [a, b, c] = [Number(m[1]), Number(m[2]), Number(m[3])];
  const raw = Buffer.from(text.slice(a + 1, b - 1), 'hex');
  // Длина DER из заголовка SEQUENCE: хвост /Contents — нули дополнения.
  const n = raw[1]! & 0x80 ? raw[1]! & 0x7f : 0;
  const len = n ? 2 + n + raw.subarray(2, 2 + n).reduce((acc, x) => acc * 256 + x, 0) : 2 + raw[1]!;
  return {
    cms: raw.subarray(0, len),
    signed: Buffer.concat([pdf.subarray(0, a), pdf.subarray(b, b + c)]),
  };
}

/** `openssl cms -verify` по вырезанным байтам; цепочка — до тестового УЦ. */
export async function opensslVerify(pdf: Buffer): Promise<void> {
  const { cms, signed } = extractSignature(pdf);
  const dir = await mkdtemp(join(tmpdir(), 'cr-sig-'));
  try {
    await writeFile(join(dir, 'sig.der'), cms);
    await writeFile(join(dir, 'data.bin'), signed);
    await run(process.env.OPENSSL ?? 'openssl', [
      'cms', '-verify', '-binary', '-inform', 'DER',
      '-in', join(dir, 'sig.der'),
      '-content', join(dir, 'data.bin'),
      '-CAfile', fixturePath('ca.pem'),
      '-purpose', 'any',
      '-out', join(dir, 'out.bin'),
    ]);
  } finally {
    await rm(dir, { recursive: true, force: true });
  }
}
```

```ts
import type { AddressInfo } from 'node:net';
import * as asn1js from 'asn1js';
import * as pkijs from 'pkijs';

export type TestTsaMode = 'ok' | 'reject' | 'wrong-nonce' | 'wrong-imprint' | 'garbage' | 'hang';

export interface TestTsa {
  url: string;
  mode: TestTsaMode;
  requests: number;
  close(): Promise<void>;
}

const ab = (b: Uint8Array) => new Uint8Array(b).slice().buffer;

async function respond(body: Buffer, mode: TestTsaMode): Promise<Uint8Array> {
  if (mode === 'garbage') return Buffer.from('not a timestamp');
  if (mode === 'reject')
    return new Uint8Array(
      new pkijs.TimeStampResp({ status: new pkijs.PKIStatusInfo({ status: 2 }) }).toSchema().toBER(),
    );
  const req = pkijs.TimeStampReq.fromBER(ab(body));
  const imprint = new Uint8Array(req.messageImprint.hashedMessage.valueBlock.valueHexView);
  if (mode === 'wrong-imprint') imprint[0] ^= 0xff;
  const nonce = new Uint8Array(req.nonce!.valueBlock.valueHexView);
  if (mode === 'wrong-nonce') nonce[nonce.length - 1] ^= 0x01;
  const tst = new pkijs.TSTInfo({
    version: 1,
    policy: '1.2.3.4.1',
    messageImprint: new pkijs.MessageImprint({
      hashAlgorithm: req.messageImprint.hashAlgorithm,
      hashedMessage: new asn1js.OctetString({ valueHex: ab(imprint) }),
    }),
    serialNumber: new asn1js.Integer({ value: Date.now() % 1_000_000 }),
    genTime: new Date(),
    nonce: new asn1js.Integer({ valueHex: ab(nonce) }),
  });
  const tstDer = new Uint8Array(tst.toSchema().toBER());
  const token = await buildSignedData({
    key: createPrivateKey(fixture('tsa.key')),
    cert: fixtureCertDer('tsa.pem'),
    chain: [],
    digestAlg: 'SHA-256',
    digest: createHash('sha256').update(tstDer).digest(),
    contentType: OID.tstInfo,
    eContent: tstDer,
  });
  return new Uint8Array(
    new pkijs.TimeStampResp({
      status: new pkijs.PKIStatusInfo({ status: 0 }),
      timeStampToken: pkijs.ContentInfo.fromBER(ab(token)),
    })
      .toSchema()
      .toBER(),
  );
}

export async function startTestTsa(mode: TestTsaMode = 'ok'): Promise<TestTsa> {
  const tsa = { mode, requests: 0 } as TestTsa;
  const server = createServer((req, res) => {
    const chunks: Buffer[] = [];
    req.on('data', (c: Buffer) => chunks.push(c));
    req.on('end', () => {
      tsa.requests++;
      if (tsa.mode === 'hang') return;
      respond(Buffer.concat(chunks), tsa.mode).then(
        (out) => res.writeHead(200, { 'content-type': 'application/timestamp-reply' }).end(Buffer.from(out)),
        () => res.writeHead(500).end(),
      );
    });
  });
  await new Promise<void>((r) => server.listen(0, '127.0.0.1', r));
  tsa.url = `http://127.0.0.1:${(server.address() as AddressInfo).port}/tsa`;
  tsa.close = () =>
    new Promise<void>((r) => {
      server.closeAllConnections();
      server.close(() => r());
    });
  return tsa;
}
```

```ts
import { createHash, sign, type KeyObject } from 'node:crypto';
import * as asn1js from 'asn1js';
import * as pkijs from 'pkijs';
import type { DigestAlg } from './p12';

export const OID = {
  data: '1.2.840.113549.1.7.1',
  signedData: '1.2.840.113549.1.7.2',
  tstInfo: '1.2.840.113549.1.9.16.1.4',
  contentType: '1.2.840.113549.1.9.3',
  messageDigest: '1.2.840.113549.1.9.4',
  signingCertV2: '1.2.840.113549.1.9.16.2.47',
  timeStampToken: '1.2.840.113549.1.9.16.2.14',
  sha256: '2.16.840.1.101.3.4.2.1',
  sha384: '2.16.840.1.101.3.4.2.2',
  sha256WithRsa: '1.2.840.113549.1.1.11',
  sha384WithRsa: '1.2.840.113549.1.1.12',
  ecdsaWithSha256: '1.2.840.10045.4.3.2',
  ecdsaWithSha384: '1.2.840.10045.4.3.3',
} as const;

const ab = (b: Uint8Array) => new Uint8Array(b).slice().buffer;
export const nodeHash = (alg: DigestAlg) => (alg === 'SHA-384' ? 'sha384' : 'sha256');

export interface SignedDataInput {
  key: KeyObject;
  /** DER сертификата подписанта. */
  cert: Uint8Array;
  chain: Uint8Array[];
  digestAlg: DigestAlg;
  /** Хэш содержимого (digestAlg). */
  digest: Uint8Array;
  /** Тип содержимого; по умолчанию id-data (подпись PDF). */
  contentType?: string;
  /** Вложенное содержимое (TSTInfo метки времени); нет — отделённая подпись. */
  eContent?: Uint8Array;
  /** Неподписанные атрибуты по готовому значению подписи (метка времени). */
  unsigned?: (signature: Uint8Array) => Promise<pkijs.Attribute[]>;
}

/** signing-certificate-v2: ESSCertIDv2 с SHA-256 сертификата (алгоритм по умолчанию не пишется, issuerSerial нет). */
function signingCertificateV2(cert: Uint8Array): asn1js.Sequence {
  const hash = createHash('sha256').update(cert).digest();
  return new asn1js.Sequence({
    value: [
      new asn1js.Sequence({
        value: [new asn1js.Sequence({ value: [new asn1js.OctetString({ valueHex: ab(hash) })] })],
      }),
    ],
  });
}

function signatureOid(key: KeyObject, alg: DigestAlg): string {
  if (key.asymmetricKeyType === 'rsa') return alg === 'SHA-384' ? OID.sha384WithRsa : OID.sha256WithRsa;
  return alg === 'SHA-384' ? OID.ecdsaWithSha384 : OID.ecdsaWithSha256;
}

/**
 * CMS SignedData (PAdES baseline B-B, §39.4): подписанные атрибуты contentType, messageDigest,
 * signing-certificate-v2 — в этом порядке (он же порядок DER SET OF), без signingTime.
 * Подпись — crypto.sign Node: RSA PKCS#1 v1.5, ECDSA в DER (R2).
 */
export async function buildSignedData(i: SignedDataInput): Promise<Uint8Array> {
  const contentType = i.contentType ?? OID.data;
  const cert = pkijs.Certificate.fromBER(ab(i.cert));
  const digestOid = i.digestAlg === 'SHA-384' ? OID.sha384 : OID.sha256;
  const signedAttrs = new pkijs.SignedAndUnsignedAttributes({
    type: 0,
    attributes: [
      new pkijs.Attribute({ type: OID.contentType, values: [new asn1js.ObjectIdentifier({ value: contentType })] }),
      new pkijs.Attribute({ type: OID.messageDigest, values: [new asn1js.OctetString({ valueHex: ab(i.digest) })] }),
      new pkijs.Attribute({ type: OID.signingCertV2, values: [signingCertificateV2(i.cert)] }),
    ],
  });
  // Подписывается DER атрибутов с тегом SET (0x31), а не [0] IMPLICIT.
  const toSign = new Uint8Array(signedAttrs.toSchema().toBER());
  toSign[0] = 0x31;
  const signature = sign(nodeHash(i.digestAlg), toSign, i.key);
  const signerInfo = new pkijs.SignerInfo({
    version: 1,
    sid: new pkijs.IssuerAndSerialNumber({ issuer: cert.issuer, serialNumber: cert.serialNumber }),
    digestAlgorithm: new pkijs.AlgorithmIdentifier({ algorithmId: digestOid }),
    signedAttrs,
    signatureAlgorithm: new pkijs.AlgorithmIdentifier({
      algorithmId: signatureOid(i.key, i.digestAlg),
      ...(i.key.asymmetricKeyType === 'rsa' ? { algorithmParams: new asn1js.Null() } : {}),
    }),
    signature: new asn1js.OctetString({ valueHex: ab(signature) }),
  });
  const unsigned = i.unsigned ? await i.unsigned(signature) : [];
  if (unsigned.length)
    signerInfo.unsignedAttrs = new pkijs.SignedAndUnsignedAttributes({ type: 1, attributes: unsigned });
  const signed = new pkijs.SignedData({
    version: contentType === OID.data ? 1 : 3,
    encapContentInfo: new pkijs.EncapsulatedContentInfo({
      eContentType: contentType,
      ...(i.eContent ? { eContent: new asn1js.OctetString({ valueHex: ab(i.eContent) }) } : {}),
    }),
    digestAlgorithms: [new pkijs.AlgorithmIdentifier({ algorithmId: digestOid })],
    certificates: [i.cert, ...i.chain].map((d) => pkijs.Certificate.fromBER(ab(d))),
    signerInfos: [signerInfo],
  });
  return new Uint8Array(
    new pkijs.ContentInfo({ contentType: OID.signedData, content: signed.toSchema(true) }).toSchema().toBER(),
  );
}

/** Неподписанный атрибут signature-time-stamp (B-T). */
export function timestampAttribute(token: Uint8Array): pkijs.Attribute {
  return new pkijs.Attribute({ type: OID.timeStampToken, values: [asn1js.fromBER(ab(token)).result] });
}
```

```ts
import { randomBytes } from 'node:crypto';
import * as asn1js from 'asn1js';
import * as pkijs from 'pkijs';
import { AppError } from '../../../lib/errors';
import { OID } from './cms';

/** Метка времени RFC 3161 на SHA-256 значения подписи; возвращает DER TimeStampToken. */
export type TsaClient = (imprint: Uint8Array, deadline: number) => Promise<Uint8Array>;

export const tsaUnavailable = (cause?: unknown) =>
  new AppError('TSA_UNAVAILABLE', 502, 'служба меток времени недоступна', undefined, cause);
const timeout = () => new AppError('TIMEOUT', 504, 'превышено время ожидания');

const ab = (b: Uint8Array) => new Uint8Array(b).slice().buffer;
const same = (a: ArrayBuffer | Uint8Array, b: Uint8Array) => Buffer.from(a as Uint8Array).equals(Buffer.from(b));

/** Ответ проверяется: статус granted/grantedWithMods, отпечаток и nonce совпадают (§39.4). */
function tokenFrom(body: Uint8Array, imprint: Uint8Array, nonce: Uint8Array): Uint8Array {
  const resp = pkijs.TimeStampResp.fromBER(ab(body));
  const status = resp.status.status;
  if ((status !== 0 && status !== 1) || !resp.timeStampToken) throw new Error(`статус ответа ${status}`);
  const signed = new pkijs.SignedData({ schema: resp.timeStampToken.content });
  const content = signed.encapContentInfo.eContent;
  if (!content) throw new Error('метка без TSTInfo');
  const tst = pkijs.TSTInfo.fromBER(content.getValue());
  if (!same(tst.messageImprint.hashedMessage.valueBlock.valueHexView, imprint))
    throw new Error('отпечаток метки не совпадает');
  if (!tst.nonce || !same(tst.nonce.valueBlock.valueHexView, nonce)) throw new Error('nonce метки не совпадает');
  return new Uint8Array(resp.timeStampToken.toSchema().toBER());
}

export function createTsaClient(url: string, timeoutMs: number): TsaClient {
  return async (imprint, deadline) => {
    const left = deadline - Date.now();
    if (left <= 0) throw timeout();
    const byDeadline = left < timeoutMs;
    const nonce = randomBytes(8);
    // Положительное целое без ведущего нулевого байта: DER совпадёт с ответом байт в байт.
    nonce[0] = nonce[0]! & 0x7f || 1;
    const request = new pkijs.TimeStampReq({
      version: 1,
      messageImprint: new pkijs.MessageImprint({
        hashAlgorithm: new pkijs.AlgorithmIdentifier({ algorithmId: OID.sha256 }),
        hashedMessage: new asn1js.OctetString({ valueHex: ab(imprint) }),
      }),
      nonce: new asn1js.Integer({ valueHex: ab(nonce) }),
      certReq: true,
    });
    let body: Uint8Array;
    try {
      const res = await fetch(url, {
        method: 'POST',
        headers: { 'content-type': 'application/timestamp-query' },
        body: Buffer.from(request.toSchema().toBER()),
        signal: AbortSignal.timeout(Math.min(left, timeoutMs)),
      });
      if (!res.ok) throw new Error(`HTTP ${res.status}`);
      body = new Uint8Array(await res.arrayBuffer());
    } catch (e) {
      if (byDeadline && (e as Error).name === 'TimeoutError') throw timeout();
      throw tsaUnavailable(e);
    }
    try {
      return tokenFrom(body, imprint, nonce);
    } catch (e) {
      throw tsaUnavailable(e);
    }
  };
}
```

```ts
import { createHash } from 'node:crypto';
import type { CertificateInfo } from '@carbone-reports/shared';
import { buildSignedData, timestampAttribute } from './cms';
import type { DigestAlg, P12Contents } from './p12';
import type { TsaClient } from './tsa';

/** Запас /Contents сверх сертификатов: подпись, атрибуты и метка времени (§39.4). */
export const CMS_RESERVE_EXTRA = 12_288;

/**
 * Способ подписи (§39.4): в 2.9.0 — ключ из .p12; ГОСТ через КриптоПро DSS — будущая реализация.
 * Подготовка PDF и штамп от реализации не зависят.
 */
export interface CmsSigner {
  readonly info: CertificateInfo;
  readonly digestAlg: DigestAlg;
  /** Сколько байт может занять CMS (R4). */
  readonly reserveBytes: number;
  createCms(digest: Uint8Array, deadline: number): Promise<Uint8Array>;
}

export class P12Signer implements CmsSigner {
  readonly reserveBytes: number;

  constructor(
    private readonly p12: P12Contents,
    private readonly tsa: TsaClient | null,
  ) {
    this.reserveBytes =
      [p12.cert, ...p12.chain].reduce((n, c) => n + c.length, 0) + CMS_RESERVE_EXTRA;
  }

  get info(): CertificateInfo {
    return this.p12.info;
  }

  get digestAlg(): DigestAlg {
    return this.p12.digestAlg;
  }

  /** Подпись получит метку времени (настроена служба меток). */
  get timestamped(): boolean {
    return this.tsa !== null;
  }

  createCms(digest: Uint8Array, deadline: number): Promise<Uint8Array> {
    const tsa = this.tsa;
    return buildSignedData({
      key: this.p12.key,
      cert: this.p12.cert,
      chain: this.p12.chain,
      digestAlg: this.p12.digestAlg,
      digest,
      unsigned: tsa
        ? async (signature) => [
            timestampAttribute(await tsa(createHash('sha256').update(signature).digest(), deadline)),
          ]
        : undefined,
    });
  }
}
```

```ts
import { createHash } from 'node:crypto';
import type { CertificateInfo, PdfSignaturePosition } from '@carbone-reports/shared';
import type { PdfSignPreparer } from '../../../deps';
import { AppError } from '../../../lib/errors';
import { nodeHash } from './cms';
import { fillByteRange, insertCms, signedRanges } from './embed';
import type { SignPrepareJob, StampLines } from './prepare';
import type { CmsSigner } from './signer';

export interface SignPdfOptions {
  position: PdfSignaturePosition;
  now: Date;
  /** Часовой пояс штампа (config.tz). */
  timeZone: string;
  /** Срок отчёта, мс от эпохи. */
  deadline: number;
  prepare: PdfSignPreparer;
}

function left(deadline: number): number {
  const ms = deadline - Date.now();
  if (ms <= 0) throw new AppError('TIMEOUT', 504, 'превышено время ожидания');
  return ms;
}

/** Строки штампа (§39.5): даты и время — в часовом поясе timeZone. */
export function stampLines(info: CertificateInfo, now: Date, timeZone: string): StampLines {
  const date = new Intl.DateTimeFormat('ru-RU', { timeZone, day: '2-digit', month: '2-digit', year: 'numeric' });
  const time = new Intl.DateTimeFormat('ru-RU', { timeZone, hour: '2-digit', minute: '2-digit', hourCycle: 'h23' });
  return [
    'ДОКУМЕНТ ПОДПИСАН ЭЛЕКТРОННОЙ ПОДПИСЬЮ',
    `Сертификат: ${info.serial}`,
    `Владелец: ${info.subjectCn}`,
    `Действителен: с ${date.format(new Date(info.notBefore))} по ${date.format(new Date(info.notAfter))}`,
    `Подписан: ${date.format(now)} ${time.format(now)}`,
  ];
}

/** Подписанный PDF (§39.4): подготовка в пуле, хэш ByteRange, CMS, вставка — всё в пределах deadline. */
export async function signPdf(pdf: Buffer, signer: CmsSigner, o: SignPdfOptions): Promise<Buffer> {
  const job: SignPrepareJob = {
    position: o.position,
    lines: stampLines(signer.info, o.now, o.timeZone),
    contentsBytes: signer.reserveBytes,
    signedAt: o.now.toISOString(),
  };
  const prepared = await o.prepare(pdf, job, left(o.deadline));
  const hole = fillByteRange(prepared, signer.reserveBytes);
  const hash = createHash(nodeHash(signer.digestAlg));
  for (const part of signedRanges(prepared, hole)) hash.update(part);
  const cms = await signer.createCms(hash.digest(), o.deadline);
  left(o.deadline);
  insertCms(prepared, hole, cms);
  return prepared;
}
```

```ts
import { IdParams, type CertificateInfo, type MyCertificate } from '@carbone-reports/shared';
import { eq } from 'drizzle-orm';
import type { FastifyRequest } from 'fastify';
import type { App } from '../../app';
import { userCertificates, users } from '../../db/schema';
import type { AppDeps } from '../../deps';
import { encryptSecret } from '../../lib/crypto';
import { AppError, badRequest, notFound } from '../../lib/errors';
import { currentUser, type Guards } from '../auth/guards';
import { P12Error, readP12 } from '../pdf/sign/p12';
import { loadUserCertificate, p12FieldError, toCertificateInfo } from './certificates';

/** Чтение формы загрузки: лимит части — 1 МБ (сообщение о 50 КБ даёт readP12, а не плагин). */
async function readCertificateUpload(req: FastifyRequest): Promise<{ file: Buffer; password: string }> {
  let file: Buffer | undefined;
  let password: string | undefined;
  for await (const part of req.parts({ limits: { fileSize: 1024 * 1024 } })) {
    if (part.type === 'file') {
      if (part.fieldname !== 'file') throw badRequest('файл передаётся в поле file');
      file = await part.toBuffer();
    } else if (part.fieldname === 'password') password = String(part.value);
  }
  if (!file) throw badRequest('файл не передан');
  if (!password)
    throw new AppError('VALIDATION', 400, 'неверные данные запроса', [{ path: '/password', message: 'укажите пароль' }]);
  return { file, password };
}

export function registerSignatureRoutes(app: App, deps: AppDeps, guards: Guards): void {
  const { db } = deps;

  app.get('/api/me/certificate', { preHandler: guards.requireUser }, async (req): Promise<MyCertificate> => {
    const row = await loadUserCertificate(db, currentUser(req).id);
    return { certificate: row ? toCertificateInfo(row) : null };
  });

  app.post('/api/me/certificate', { preHandler: guards.requireUser }, async (req, reply) => {
    const { file, password } = await readCertificateUpload(req);
    let info: CertificateInfo;
    try {
      info = readP12(file, password).info;
    } catch (e) {
      if (e instanceof P12Error) throw p12FieldError(e);
      throw e;
    }
    const values = {
      p12Enc: encryptSecret(file.toString('base64'), deps.config.encryptionKey),
      subjectCn: info.subjectCn,
      issuer: info.issuer,
      serial: info.serial,
      fingerprint: info.fingerprint,
      keyAlg: info.keyAlg,
      notBefore: new Date(info.notBefore),
      notAfter: new Date(info.notAfter),
    };
    await db
      .insert(userCertificates)
      .values({ userId: currentUser(req).id, ...values })
      .onConflictDoUpdate({ target: userCertificates.userId, set: { ...values, createdAt: new Date() } });
    return reply.status(201).send(info);
  });

  app.delete('/api/me/certificate', { preHandler: guards.requireUser }, async (req, reply) => {
    await db.delete(userCertificates).where(eq(userCertificates.userId, currentUser(req).id));
    return reply.status(204).send();
  });

  app.delete(
    '/api/users/:id/certificate',
    { preHandler: guards.requireAdmin, schema: { params: IdParams } },
    async (req, reply) => {
      const [user] = await db.select({ id: users.id }).from(users).where(eq(users.id, req.params.id));
      if (!user) throw notFound('пользователь');
      await db.delete(userCertificates).where(eq(userCertificates.userId, user.id));
      return reply.status(204).send();
    },
  );
}
```

```ts
import { IdParams, MAX_PDF_RESULT_BYTES, SignRunBody, type RunSignature } from '@carbone-reports/shared';
import { eq } from 'drizzle-orm';
import type { FastifyRequest } from 'fastify';
import type { App } from '../../app';
import { reportRunSignatures, reportRuns } from '../../db/schema';
import type { AppDeps } from '../../deps';
import { decryptSecret } from '../../lib/crypto';
import { Deadline } from '../../lib/deadline';
import { AppError, badRequest, conflict, notFound } from '../../lib/errors';
import { currentUser, type Guards } from '../auth/guards';
import { P12Error, readP12, type P12Contents } from '../pdf/sign/p12';
import { signPdf } from '../pdf/sign/sign-pdf';
import { P12Signer } from '../pdf/sign/signer';
import { createTsaClient } from '../pdf/sign/tsa';
import {
  readSnapshotFile,
  RUN_FILE_LOCK_CLASS,
  signedPath,
  snapshotGone,
  snapshotPaths,
  snapshotExt,
  toRunSignature,
} from '../reports/snapshot';
import { loadUserCertificate } from './certificates';

const unavailable = () => badRequest('подпись для этого отчёта недоступна');
const wrongPassword = () =>
  new AppError('VALIDATION', 400, 'неверные данные запроса', [{ path: '/password', message: 'неверный пароль к ключу' }]);
const tooMany = () =>
  new AppError('TOO_MANY_ATTEMPTS', 429, 'слишком много неверных паролей — попробуйте через 15 минут');

export function registerSignRunRoute(app: App, deps: AppDeps, guards: Guards): void {
  const { db, storage, config } = deps;
  // R8: считаются только неверные пароли; nameSpace читает FallbackStore.child (как лимит входа по IP).
  const limitOptions = {
    max: 5,
    timeWindow: '15 minutes',
    nameSpace: 'cr:rl-sign:',
    keyGenerator: (req: FastifyRequest) => currentUser(req).id,
  };
  const limit = app.createRateLimit(limitOptions);

  app.post(
    '/api/runs/:id/sign',
    { preHandler: guards.requireUser, schema: { params: IdParams, body: SignRunBody } },
    async (req, reply) => {
      const deadline = new Deadline(config.reportTimeoutMs);
      const me = currentUser(req);
      const [run] = await db.select().from(reportRuns).where(eq(reportRuns.id, req.params.id));
      // Подписывает только владелец (§39.3): чужой запуск неотличим от несуществующего, и для администратора.
      if (!run || run.userId !== me.id) throw notFound('запуск');
      const position = run.signaturePosition;
      if (!run.snapshot || run.status !== 'ok' || run.fileDeleted || !run.filePath || !position)
        throw unavailable();
      const cert = await loadUserCertificate(db, me.id);
      if (!cert) throw badRequest('загрузите сертификат на странице «Моя подпись»');
      const now = new Date();
      if (now < cert.notBefore) throw badRequest('сертификат ещё не действует');
      if (now > cert.notAfter) throw badRequest('срок действия сертификата истёк');
      if ((await limit(req, { increment: false })).remaining <= 0) throw tooMany();

      const result: RunSignature = await deps.runFileGate(
        RUN_FILE_LOCK_CLASS,
        `${run.id}:signed`,
        deadline,
        async (tx) => {
          // FOR SHARE: очистка ждёт конца подписи (как сборка форматов, §24.2).
          const [cur] = await tx
            .select({ fileDeleted: reportRuns.fileDeleted })
            .from(reportRuns)
            .where(eq(reportRuns.id, run.id))
            .for('share');
          if (!cur || cur.fileDeleted) throw snapshotGone();
          const [done] = await tx
            .select({ runId: reportRunSignatures.runId })
            .from(reportRunSignatures)
            .where(eq(reportRunSignatures.runId, run.id));
          if (done) throw conflict('отчёт уже подписан');

          let p12: P12Contents;
          try {
            p12 = readP12(Buffer.from(decryptSecret(cert.p12Enc, config.encryptionKey), 'base64'), req.body.password, now);
          } catch (e) {
            if (e instanceof P12Error && e.field === 'password') {
              await limit(req);
              throw wrongPassword();
            }
            if (e instanceof P12Error) throw badRequest(e.message);
            throw e;
          }
          const signer = new P12Signer(
            p12,
            config.signTsaUrl ? createTsaClient(config.signTsaUrl, config.signTsaTimeoutMs) : null,
          );
          const pdf = await readSnapshotFile(deps, snapshotPaths(run.id, snapshotExt(run.filePath!)).out('pdf'));
          const signed = await signPdf(pdf, signer, {
            position,
            now,
            timeZone: config.tz,
            deadline: Date.now() + deadline.remaining(),
            prepare: deps.pdfSignPrepare,
          });
          if (signed.length > MAX_PDF_RESULT_BYTES) throw badRequest('итоговый PDF больше 100 МБ');
          const path = signedPath(run.id);
          await storage.write(path, signed);
          try {
            const [row] = await tx
              .insert(reportRunSignatures)
              .values({
                runId: run.id,
                userId: me.id,
                signerCn: p12.info.subjectCn,
                fingerprint: p12.info.fingerprint,
                signedAt: now,
                timestamped: signer.timestamped,
                filePath: path,
              })
              .returning();
            return toRunSignature(row!);
          } catch (e) {
            await storage.remove(path).catch((err) => req.log.warn({ err, runId: run.id }, 'подписанный файл не удалён'));
            throw e;
          }
        },
      );
      return reply.status(201).send(result);
    },
  );
}
```
