# 2.15.0: справка по шаблонам на 7 языках (этап 3) — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** «Справка по шаблонам» показывается на языке интерфейса (7 языков), а результаты её примеров совпадают с тем, что даёт Carbone для того же «Языка отчёта»; `pnpm help:check` сверяет все языки.

**Architecture:** содержимое справки — по модулю на язык (`apps/web/src/pages/admin/help/content/<locale>.ts`) с общими типами; `ru` — в чанке страницы справки, остальные — динамическим импортом. Подписи страницы — новое пространство имён каталога `help`. Тест структуры сверяет модули между собой; `help:check` рендерит примеры каждого языка с `CARBONE_LANGS[locale]`.

**Tech Stack:** React 19 + Gravity UI, i18next/react-i18next (уже есть), vitest, tsx (`scripts/help-check.ts`), встроенный Carbone (`packages/carbone`).

**Spec:** `docs/superpowers/specs/2026-10-02-carbone-reports-design.md`, §46 (контекст — §23 справка, §44 этап 1, §45 язык отчёта).

## Global Constraints

- Node 22: `export PATH=$HOME/.nvm/versions/node/v22.17.0/bin:$PATH`.
- Тесты веба: `pnpm --filter @carbone-reports/web test` (или `exec vitest run <файлы>`); проверка справки: `pnpm help:check` (`-- --locale <l>`, `-- --self-test`). Не запускать два набора одновременно; `render-onlyoffice.int.test.ts` не запускать никогда. Тайм-ауты 5 с под нагрузкой — перепроверять файл отдельно и писать оба результата.
- Перед коммитом: `pnpm typecheck`, `pnpm exec prettier --check .`, `pnpm i18n:check`, eslint на `apps packages scripts` (ошибки локального `cades/cadesplugin_api.js` вне репозитория не считаются).
- `LOCALES = ['ru','en','es','pt-BR','fr','de','zh-CN']`; модули: `ru.ts`, `en.ts`, `es.ts`, `pt-BR.ts`, `fr.ts`, `de.ts`, `zh-CN.ts`.
- `ru.ts` — нынешний `content.ts` дословно (тексты, данные, результаты не меняются; существующие проверки и `help:check` для `ru` дают прежний результат).
- Не переводятся: теги Carbone, имена полей (`d.…`, `c.…`), имена форматтеров и их порядок, SQL (`sql.key`, `sql.mode`, `sql.text`), `id`, флаги. Переводятся: заголовки, `intro`, `note`, `limits[].title/instead`, постоянный текст в шаблонах, значения в `data` (ключи JSON те же), `result` (получается из Carbone, для `picture`/`rich` — описание словами).
- Заметки с русской спецификой (рубль, `formatC`/`convCurr` из рубля, меню Word, Госуслуги) — переписать по смыслу для языка; утверждения о поведении системы не меняются. Строковые аргументы форматтеров можно заменить на привычные для языка, если `help:check --locale` подтверждает результат.
- Переводы — по глоссарию `docs/localization.md` и правилам пунктуации языков (как в 2.13.0); статус «вычитан носителем: нет».
- Коммиты: сообщение в стиле репозитория, последний `-m` — абзац из двух строк:
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`
  `Claude-Session: https://claude.ai/code/session_01QhpYjvmQgUdZAFnqrogAEB`
  Ветка `feat/2.15.0`; не переключать ветки, не пушить, не мержить.
- Новых зависимостей нет. Docker-образы не собирать; `.env` и `certs/` не читать.

## Решения контроллера (до исполнения)

- **Загрузка:** `loadHelpContent(locale): Promise<HelpContent>` в `content/index.ts`; `ru` — статический импорт, остальные — `import()` по таблице `Record<Exclude<Locale,'ru'>, () => Promise<HelpContent>>`. Пока модуля языка нет (Task 1), запись в таблице отсутствует и `loadHelpContent` возвращает `ru` без сообщения об ошибке; с появлением модуля (Tasks 2–7) задача добавляет одну строку в таблицу. Ошибка `import()` — `ru` и флаг `failed: true` (страница показывает `Alert` из каталога `help`).
- **Тест структуры** — `content/structure.test.ts`: для каждого модуля из таблицы (кроме `ru`) сравнение с `ru` по правилам §46.4; добавление модуля автоматически включает его в тест.
- **`content.test.ts`** параметризуется по всем доступным модулям (`describe.each`), проверки, привязанные к русским словам (заголовки разделов), остаются только для `ru`.
- **`help:check`** перебирает доступные модули; `--locale <l>` — только один; сообщение «недоступно в бесплатной версии» — `createTranslator(locale)`.
- **Порядок языков в задачах:** `en` → `de` → `fr` → `es` → `pt-BR` → `zh-CN` (по одному языку на задачу; `en` первым — от него проще переводить романские).

## Review Focus

1. Модуль языка не загрузился (чанк недоступен после обновления версии) — справка на русском и понятное сообщение, а не пустая страница. Тест — Task 1.
2. Пользователь сменил язык интерфейса на открытой справке — содержимое переключается без перезагрузки, якоря (`#fmt-money`) продолжают работать. Тест — Task 1.
3. Кнопка «Копировать» копирует шаблон того языка, который показан (с переведённым текстом шаблона). Тест — Task 2.
4. Пример с `formatC` на `en`/`de`/`zh-CN` показывает валюту языка отчёта (USD/EUR/CNY «¥»), а заметка к нему не говорит про рубли. Проверка — `help:check --locale` и чтение заметки ревьюером, Tasks 2, 3, 7.
5. Таблицы Word в примерах («| ячейка |») с переведённым текстом остаются каноничными и проходят `--self-test`. Тест — `content.test.ts` по всем модулям.
