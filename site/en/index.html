Carbone Reports

Reports from Word and Excel templates filled with data from your PostgreSQL databases. Templates are edited right in the browser; the finished document comes out as PDF, DOCX or XLSX, with an electronic signature, including GOST.

Source code and installation on GitHub

Sign-in

Local accounts, LDAP/Active Directory or Keycloak (OpenID Connect). The interface language can be chosen before signing in.

Report catalog

Reports are grouped into categories; everyone sees only what they have access to.

Running with parameters

The form is built from the template's parameters: dates, numbers and lists, including dependent lists from SQL queries.

History

Every generated report is kept: open it, download it in another format or sign it later.

Queries and parameters

Template data comes from SQL queries to connected databases. Queries run read-only.

Templates in the browser

The template document opens in the built-in OnlyOffice editor — no Word or Excel needed.

PDF and electronic signatures

PDF password protection, page numbering and signing: with the user's certificate (.p12) or with a GOST key via CryptoPro — the GOST key never leaves the user's computer.

Access and roles

Access to reports is granted by groups and categories; roles separate users, template authors and access managers.

Users

Accounts, roles and blocking in one list.

Data sources

Connections to PostgreSQL databases with a connection test; passwords are stored encrypted.
