Carbone Reports

Отчёты по шаблонам Word и Excel с данными из ваших баз PostgreSQL. Шаблоны правятся прямо в браузере, готовый документ — в PDF, DOCX или XLSX, с электронной подписью, в том числе по ГОСТ.

Исходный код и установка на GitHub

Вход

Локальные учётные записи, LDAP/Active Directory или Keycloak (OpenID Connect). Язык интерфейса можно выбрать до входа.

Каталог отчётов

Отчёты разложены по категориям; каждый видит только то, к чему ему открыт доступ.

Запуск с параметрами

Форма строится из параметров шаблона: даты, числа, списки, в том числе зависимые списки из SQL-запросов.

История

Все сформированные отчёты сохраняются: их можно открыть, скачать в другом формате или подписать позже.

Запросы и параметры

Данные для шаблона — SQL-запросы к подключённым базам. Запросы выполняются только на чтение.

Шаблон в браузере

Документ шаблона открывается во встроенном редакторе OnlyOffice — Word и Excel не нужны.

PDF и электронная подпись

Защита PDF паролем, нумерация страниц и подпись: сертификатом пользователя (.p12) или ключом по ГОСТ через КриптоПро — ключ ГОСТ не покидает компьютер пользователя.

Доступ и роли

Доступ к отчётам — по группам и категориям; роли разделяют пользователей, авторов шаблонов и тех, кто управляет доступом.

Пользователи

Учётные записи, роли и блокировка в одном списке.

Источники данных

Подключения к базам PostgreSQL с проверкой соединения; пароли хранятся зашифрованными.
